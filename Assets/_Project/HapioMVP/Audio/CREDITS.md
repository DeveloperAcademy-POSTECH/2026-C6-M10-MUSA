# Audio Credits

합이오(Hapio)에 사용한 외부 사운드의 출처와 라이선스 기록.
**새 소리를 추가할 때마다 한 줄씩 적는다.** 출시·발표 때 이 파일이 곧 출처 표기가 된다.

## 적는 규칙

- **파일명** — 프로젝트 안의 이름 (`sfx_jangsanbeom_hit_01.wav`)
- **원본 이름** — 다운로드했을 때의 이름 (나중에 다시 찾을 때 필요)
- **출처** — 다운로드한 페이지 URL (사이트 메인이 아니라 그 소리/팩 페이지)
- **제작자** — 페이지에 적힌 이름
- **라이선스** — 페이지에 적힌 그대로 (예: CC0, CC-BY 4.0, Standard Unity Asset Store EULA)
- **표기 필요** — CC-BY 계열이면 ✅ (아래 "표기" 칸에 적은 문구를 크레딧 화면에 그대로 넣어야 함)
- **수정** — 자르기·볼륨·피치 등 편집했으면 무엇을 했는지

## ⚠️ 쓰기 전 확인

- **CC-BY-NC(비상업)** 는 쓰지 않는다 — 나중에 출시·공개 시연하면 문제가 됨
- **Unity Asset Store** 에셋은 게임 안에서 쓰는 건 되지만, 소리 파일 자체를 따로 배포하면 안 됨
- 라이선스가 페이지에 안 보이면 **쓰지 않는다**
