# 장산범 v1 — 상세 도면 기반 3D 제작본

이 모델은 몸통과 다리가 보이지 않도록 앞 도포를 겹쳐 닫고, 머리카락을 덧대어 지면까지 덮었습니다. 소매 끝은 손등 가까이까지 내려 손목을 가립니다. 손가락은 관절 굴곡 없이 이어지는 굵은 형태이며 손톱도 두껍게 했습니다. 색상은 밝은 아이보리이며, 비대칭 손 높이와 무거운 애니메이션 타이밍을 사용합니다.

도포 아래에 가려질 몸통·다리 표면은 제거해 동작 중 그 표면이 드러나지 않도록 했습니다. 내부 뼈는 유지합니다. 손가락은 2마디 본을 유지하되 외형은 손가락별 첫 본에 연결해 하나의 굵은 형태로 움직입니다.

원화의 가려진 부분을 해석한 모델입니다. 실측 비교로 검증된 “99% 동일 모델”은 아니며, 편집 가능한 메시와 비교용 렌더를 제공합니다. 원화와 생성 도면이 다른 경우 첨부 원화를 우선하세요. 참고 도면은 Blender 내부에 포함되어 있습니다.

## 가장 쉽게 확인하기 — Unity 미리보기 씬

1. `Jangsanbeom_v1_Unity.unitypackage`를 Unity에 가져옵니다. `Assets/Jangsanbeom_v1` 폴더에 들어갑니다.
2. `Assets/Jangsanbeom_v1/Unity/Generated/Jangsanbeom_Preview.unity`를 더블클릭합니다.
3. 화면 맨 위 ▶를 누르고 **Game 탭**으로 이동합니다.
4. 왼쪽 버튼에서 `Idle`, `Claw Attack`, `Grab` 등을 누릅니다. Replay로 다시 재생하고 Speed로 확인 속도를 바꿀 수 있습니다.

이 버튼은 검수용 미리보기 씬에만 있습니다. 게임에 사용할 기본 프리팹에는 버튼 UI가 포함되지 않습니다. 미리보기 씬의 `Animation Buttons` 오브젝트가 버튼을 표시합니다.

프로젝트의 렌더링 방식이 달라 재질이 분홍색이면 **Tools → Jangsanbeom v1 → Create Materials and Prefab**을 실행하고, **Create Preview Scene**으로 미리보기 씬을 다시 만드세요. Built-in Standard와 URP Lit을 지원하며 HDRP는 별도 재질 변환이 필요합니다. 씬을 다시 만들 때 현재 작업의 저장 여부를 확인합니다.

## 제공 파일

- `Jangsanbeom.blend`: 원본 메시, 커스텀 FK 리그, 10개 Action, 렌더용 스튜디오와 숨겨진 참고 이미지.
- `Jangsanbeom.fbx`: 모델·커스텀 스켈레톤·10개 클립.
- `Animations/`: 각 동작을 독립적으로 가져오는 FBX 10개.
- `Textures/Jangsanbeom_Palette.png`: 256×256 팔레트. Blender와 FBX에도 텍스처를 포함했습니다.
- `Previews/`: 실제 3D 모델의 정면·측면·후면 렌더, 공격 GIF와 클립별 포즈.
- `Unity/`: 재질·프리팹 생성 도구와 미리보기 버튼 스크립트.
- `Unity_Validation.txt`: 실제 Unity 가져오기 검사 결과.
- `asset_manifest.json`: 메시와 리그 사양, 클립 범위, 타격 마커.

FBX를 직접 복사하는 경우 프로젝트 안 폴더 이름을 `Assets/Jangsanbeom_v1`로 맞춘 뒤 위 Tools 메뉴를 실행하세요. Blender 파일이나 Reference 이미지를 Unity로 복사할 필요는 없습니다.

## 사양과 리그

미터 단위, 약 2.8m, 30fps. **2,108 정점 / 4,047 삼각형 / 58개 본 / 정점당 최대 3개 본 영향**. 하나의 스킨 메시 안에 겹친 머리카락·손가락 등 여러 분리된 표면이 들어 있습니다. 평평한 면과 단순 색상 팔레트를 사용하는 로우폴리 방식입니다.

Rig는 **Generic**, 비휴머노이드입니다. `Root → Hip → Spine → Chest → Neck → Head`, 좌우 Shoulder/UpperArm/Forearm/Hand, 손당 5개의 2마디 Finger, 다리·발, 앞머리·망토 체인이 있습니다. 별도의 소매 전용 본은 사용하지 않습니다.

Blender 5.2.1에서 제작했습니다. `Jangsanbeom_Rig`를 선택하고 Pose Mode에서 본을 편집하세요. 기본 Action은 Idle, 프레임 범위는 1–181입니다. 도면은 `REFERENCE` 컬렉션 안에서 숨겨져 있습니다. 외형을 편집할 때 렌더용 스튜디오와 참고 이미지는 FBX 내보내기 대상에서 제외하세요.

Move는 제자리 루프입니다. Apply Root Motion은 기본으로 꺼져 있으며 이동·충돌·피해 판정·AI·음성은 게임 로직에 연결해야 합니다. Vanish는 수축 애니메이션으로 파편과 디졸브 VFX는 포함하지 않습니다. 천과 머리카락은 본 키프레임 기반이며, 실시간 천 충돌이 아니므로 지형과 극단적인 포즈에 맞춘 접촉 조정이 필요할 수 있습니다.
