# 구미호 Unity 제작본

## 결과와 일치 범위

제공된 단독 이미지와 턴어라운드를 참고해 만든 입체 메시입니다. 9개 꼬리, 붉은 끝부분, 주둥이와 코, 붉은 눈화장과 이마 문양, 귀 안쪽, 목과 등의 갈기, 검은 네 다리, 붉은 발톱과 발바닥, 금색 장식 3개와 붉은 술을 포함합니다.

**사진과 완전히 동일한 결과나 원본 면을 하나씩 복원한 수작업 리토폴로지로 검증된 파일은 아닙니다.** 실루엣, 얼굴, 귀, 갈기, 꼬리 깊이를 반복 수정했지만 얼굴의 비율, 갈기의 겹침과 각 면의 위치, 다리의 자세, 꼬리별 면 분할에는 차이가 남아 있습니다. 일부 세분화는 기존 평면을 유지하는 분할이므로 삼각형 수가 원화 일치도를 뜻하지 않습니다. 아래 비교 이미지를 확인해 아트 승인 여부를 판단할 수 있습니다.

- `Preview/Reference_Comparison.png`: 단독 레퍼런스와 실제 Blender 렌더 비교.
- `Preview/Turnaround_Comparison.png`: 여섯 방향 레퍼런스와 정사영 렌더 비교.
- `Preview/SixViews.png`: 정면, 좌측, 우측, 후면, 위, 아래.
- `Preview/Unity_URP.png`: 실제 Unity URP 렌더.

## 기존 Unity 프로젝트에 가져오기

1. URP가 설치된 Unity 프로젝트에서 `Assets > Import Package > Custom Package`를 선택합니다.
2. `Gumiho_URP.unitypackage`를 가져옵니다.
3. `Assets/Gumiho/Prefabs/Gumiho.prefab`을 장면으로 끌어놓습니다.
4. `Assets/Gumiho/Scenes/Gumiho_Preview.unity`에서 예시 장면을 볼 수 있습니다.

프리팹과 재질은 미리 생성되어 있습니다. 가져온 뒤 생성 메뉴를 실행할 필요가 없습니다. 이 패키지는 기존 프로젝트의 렌더 파이프라인을 자동으로 바꾸지 않습니다. Built-in 또는 HDRP에서는 제공한 BaseColor와 MetallicSmoothness 텍스처로 해당 파이프라인의 재질을 만들어 지정해야 합니다.

## 독립 프로젝트 열기

`Gumiho_Unity_Project.zip`에는 Assets, Packages, ProjectSettings가 들어 있습니다. 압축을 풀고 Unity Hub에서 `GumihoUnity` 폴더를 추가합니다. 검증에 사용한 환경은 **Unity 6000.6.0f1 / URP 17.6.0**입니다. 다른 Unity/URP 버전의 동작은 별도 검증하지 않았습니다. 최초 실행 시 Unity가 패키지를 다운로드할 수 있습니다.

프로젝트의 `Player Views` 오브젝트에서 Player Count(3~5), Player Index를 바꾸면 둘러선 플레이어의 시야를 확인할 수 있습니다. 한 번에 카메라 하나만 활성화됩니다. 네트워크 동기화나 게임 전투 시스템은 포함하지 않습니다.

털 조각, 장식, 신체는 여러 닫힌 표면을 한 개의 스킨드 메시로 합쳤습니다. 전신이 하나의 연속적인 피부 토폴로지는 아닙니다. 평면 음영을 유지합니다. UV는 팔레트 색 지정용이며 세밀한 털 텍스처 페인팅용 전개도는 아닙니다.

## 애니메이션과 약점

- `Idle`: 2초 길이의 반복 대기, 머리와 꼬리 및 술의 작은 움직임.
- `Attack_Preview`: 1초 길이의 머리/꼬리 동작 예시.
- `Hit_Preview`: 약 0.67초 길이의 피격 동작 예시.

공격과 피격은 리깅 확인용 초안입니다. 발 고정 IK, 달리기, 충돌 타이밍, 공격 판정, 최종 전투 안무는 포함하지 않습니다. Animator의 상태를 직접 선택하거나 해당 이름으로 재생할 수 있습니다.

기획서의 방향별 약점 구조를 지원하도록 뒤쪽, 좌우 장식, 아래쪽에 수정 가능한 약점 컴포넌트와 트리거를 배치했습니다. 위치와 각도는 구현 예시이며 구미호의 확정 기획값이 아닙니다. `GumihoWeakPoint.IsVisibleFrom(cameraPosition)`을 플레이어별로 호출해 해당 방향에서 보이는지 판정합니다. 공용 오브젝트를 켜고 끄지 않으므로 서로 다른 카메라가 동시에 사용할 수 있습니다. 실제 약점 표시, 가림 판정, 네트워크 권한과 데미지는 게임 코드에서 연결해야 합니다. 약점은 대응하는 뼈대에 붙어 움직입니다.

## 검증

Unity 에디터에서 FBX 가져오기, 재질, 프리팹 생성, 꼬리 9개와 뼈대 수, 3개 애니메이션, 방향 판정을 검사했습니다. 각 애니메이션에서 9개 시점을 샘플링해 정점 값과 스킨드 메시 범위를 확인했습니다. 실제 결과는 `Unity_Validation.txt`에 있습니다. 정적 메시의 열린 경계와 비다양체 모서리는 Blender에서 검사했습니다. 자기 교차나 모든 자세의 표면 충돌이 없음을 보장하는 검사는 아닙니다.

iOS 실기기 프레임 속도, 발열, 메모리, 네트워크 동기화는 측정하지 않았습니다. 한 메시/한 재질로 구성했으나 그림자와 스키닝 비용은 게임 장면에서 프로파일링해야 합니다. LOD는 포함하지 않습니다.

## 편집 원본

`Source/Gumiho.blend`에는 텍스처가 내장되어 있습니다. Blender에서는 NLA 트랙을 활성화해 동작 초안을 확인할 수 있습니다. `Source/Gumiho.glb`는 호환 뷰어용입니다. Unity에는 포함된 FBX와 프리팹을 사용합니다. 동기화된 ADA_C6 원본 자료는 수정하지 않았습니다.
