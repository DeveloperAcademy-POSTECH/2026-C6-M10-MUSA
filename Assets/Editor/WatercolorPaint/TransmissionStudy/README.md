# 수채 투과·겹침 비교 — Editor 시제품

`C6 Lab > Experiments > Watercolor Transmission Comparison`에서 출력 폴더를 선택한다. 현재 게임의 V2 기본 표현과 기존 V3 비교 자료는 바꾸지 않는다. 출력은 저장된 실제 WhiteGourd Prefab의 일회용 복사본을 Unity에서 렌더링한 이미지다.

## 비교 열

1. `baseline-v3-cap085`: 이전 V3 비교, 층 불투명도 상한 0.85.
2. `density-transmission`: 원본 브러시의 안료 농도에 따라 투과량을 조절한다. 옅은 원본에서 가산 노이즈로 새 안료를 만들지 않는다. 진한 부분의 상한은 0.95, 안료량은 1.8이다.
3. `overlap-glazing`: 2번의 최초/새 영역 도장을 그대로 사용하고 기존 영역에 겹쳐지는 도장의 광학 두께만 0.55배로 낮춘다. 최초 1회에서는 2·3번의 최종 지도 바이트가 같아야 한다.

일반 premultiplied source-over 합성을 유지한 시각 근사다. 실제 안료의 감산 혼색, Kubelka–Munk 모델, 유체 시뮬레이션은 구현하지 않는다.

## 조정 지점

`WatercolorTransmission.shader`의 `_StudyPigmentLoad`(1.8), `_StudyWashOpacity`(0.02), `_StudyFlowStrength`(0.2), `_StudyOverlapDose`(0.55)가 실험값이다. 내보내기 코드는 같은 값을 명시적으로 바인딩하므로, 비교값을 바꾸려면 `LabWatercolorTransmissionStudy.Export`의 바인딩과 보고서 값도 함께 맞춘다. V3 원본 프로필을 수정하지 않는다. 이 값들은 공유 DEV 설정이나 게임 통신 버전이 아니다.

## 출력과 판독

- 최초 1회, 최초 + 재타격 3회, 2색 겹침, 3색 교차, 5색 완성의 3열 비교를 출력한다.
- `actual`: 기존 V3 종이·입자·음영을 열마다 동일하게 유지한다.
- `neutral`: 종이색/요철과 입자/섬유 변조를 끈다. 박의 기존 확산 음영은 남아 있으므로 Unlit 비교가 아니다.
- `surface-diagnostic-four-views.png`: 왼쪽 위는 기존, 오른쪽 위는 종이색/요철만 중립화, 왼쪽 아래는 입자/섬유 변조만 제거, 오른쪽 아래는 둘 다 제거. 모두 동일한 baseline 지도다.
- 5색 완성은 이전 비교와 같은 붉은 팔레트만 표현 단계에서 주입한다. 최초/재타격은 같은 빨강으로 고정한다. 게임 오행색과 원본 기록은 바꾸지 않는다.
- 완성 박의 겹침 비교안을 6방향으로 출력한다. `paintmap.png`는 선형 데이터 확인용이며 완성 표면 렌더와 구분한다.

## 검증 범위

`transmission-study.json`에는 판정 색/P 지도, 입력 기록의 해시/순번, 원본 자산과 Scene 보존, 같은 기록의 반복 적용·새 런타임 재생의 최종 지도 일치를 기록한다. 자산의 전체 직렬화 내용 대신 해시를 남긴다.

이 비교가 통과해도 실제 네트워크 플레이·iOS·성능·미적 승인을 통과한 것으로 해석하지 않는다. 게임 기본값 연결은 시각 평가 후 별도 작업이다.
