# 오행 페인트볼 실험 (#153)

팀 합의 전 제안용 프로토타입. Unity 메뉴 **C6 Lab → Open Gourd Paint Experiment**로 장면을 열고 Play를 누른다. Game 창 로비의 **색 자국 미리보기** 버튼으로 다섯 색을 순서대로 찍어볼 수 있다. **색 초기화**는 로비 미리보기만 초기화한다.

실제 투척: DEV → START SOLO → Yin/Yang 구슬을 직접 조합 → Combined를 위로 스와이프한다. 호스트가 승인한 명중 위치를 박 표면에 투영하여 색을 남긴다. Fire=빨강, Water=파랑, Wood=초록, Metal=노랑, Earth=갈색. 페인트는 구슬 외형 설정의 속성 재질 색 또는 공통 기본 색을 읽는다. 속성이 없는 타격은 칠하지 않는다. 오행 구슬 생성 규칙은 변경하지 않았다.

흰 박은 비교를 위한 단순한 둥근 모델이다. 칠한 곳 위에 다른 색을 덧칠할 수 있으며 회전·흔들림에도 자국이 표면에 붙어 있다. 남은 흰 면을 확인해볼 수 있다. 원래 피격 원통을 유지하고 명중 방향을 구형 표면에 투영하기 때문에 박의 정확한 메시 충돌 위치와는 차이가 있다.

이번 범위: 색 자국 표시·다섯 색·회전 유지·라운드/로비 전환 초기화. 면적 계산, 색칠 완료 조건, 협동 봉인, 크랙과 깨짐 연출은 포함하지 않는다. 종료 조건은 기존 HP다. 기본 HP 1000, 명중 피해 20이면 한 라운드 약 50개 자국이 생긴다. 셰이더는 최대 128개를 보존하며 그 이상에서는 새로운 자국을 추가하지 않는다. iOS 성능과 실제 다중 기기 표시 일치는 별도 확인해야 한다.

화면 표시는 각 기기가 받은 승인 타격으로 갱신한다. 이전 타격 전체의 저장·재접속 복원 기능은 없다. 실험 Scene만 박 페인트 컴포넌트를 사용한다. 공통 코드의 변경은 LabTarget의 승인 타격 이벤트 및 기존 호스트/클라이언트 타격 처리 지점에서 이벤트를 알리는 연결이다. 피해·승리·네트워크 패킷 형식은 변경하지 않았다.

실험 장면: `Assets/Experiments/GourdPaint/GourdPaintPrototype.unity`. 메뉴는 기본 빌드 시작 장면을 바꾸지 않는다. 원본 `Lab.unity`는 보존한다.

## 이번 검증 — 2026-10-15

Unity 6000.6.5f1에서 컴파일·실험 Scene 생성·셰이더 렌더 확인. 기존 전투 PlayMode 60/60 통과, 별도로 추가한 페인트 PlayMode 검사 1/1 통과, EditMode 88/88 통과. 승인 타격 이벤트 연결, 회전 후 로컬 자국 좌표 유지, 초기화, 잘못된 좌표 거부, 128개 한도 확인. 테스트에서 만든 다섯 색 캡처를 직접 확인했다. 사용자 손 입력, 실제 다중 기기 동기, iOS 성능은 미검증이며 시연 전에 직접 확인이 필요하다.

색상 수정: 별도 실험 팔레트를 제거하고 공격 구슬의 공통 기본 색/속성 재질 색을 사용하도록 변경했다. 화=빨강, 수=파랑, 목=초록, 금=노랑, 토=갈색. 승인 이벤트로 찍힌 화·금·토의 실제 셰이더 색상값을 확인하는 관련 PlayMode 검사 1/1 재통과. 구슬과 박의 조명 및 표면 음영 때문에 화면상의 밝기는 다를 수 있다.
