# 배경 배치 프로토타입

Unity 메뉴 **C6 Lab → Background Prototype → 실험 장면 열기 / 최초 생성**.
Play 없이 인원 3~5명과 크게 볼 플레이어를 바꾼다. 모든 시점 함께 보기를 끄면 한 시점을 크게 볼 수 있다. Hierarchy의 Painted Background Cards 아래 평면들을 이동·회전·크기 조절하면 비교 화면에 반영된다. 배치를 보존하려면 Scene을 저장한다.

장면: `Generated/BackgroundPrototype.unity`. 플레이 시 첫 번째 카메라가 표시되지만 전투·네트워크·조합판은 포함하지 않는다. 카메라 비교는 Editor 도구에서 수행한다.

**현재 배치의 3·4·5인 화면 저장**은 총 12장의 세로형 540×960 이미지를 `Library/BackgroundPrototypeCaptures`에 저장한다. 같은 파일명은 다음 캡처로 갱신된다. 이 폴더는 Git에서 제외된다.

## 표현과 임시값

- 원거리 산 8면, 대문·집·소나무·바위·풀을 고정된 평면으로 배치했다. 카메라를 따라 회전하지 않는다.
- 양면 Unlit 재질과 alpha clipping 0.18을 사용한다. 반투명 겹침 순서 문제를 줄이기 위한 프로토타입 선택이다. 수묵화의 옅은 가장자리 일부가 잘릴 수 있으므로 최종 아트는 별도 확인해야 한다.
- 구미호는 PR #123의 FBX·색상 텍스처를 실험 폴더에 복사했다. 최적화되지 않은 시각 참고용이며 실제 피격체나 #128/#129 작업과 연결하지 않았다.
- 모델 최장 축을 4로 맞추고 중심을 높이 3.35에 둔다. 위의 막대와 끈은 매달린 위치 확인용 임시 입체물이다.
- 카메라 위치 계산은 LabThrowMath.SeatPosition, 반경·높이는 LabConfig를 사용한다. 전투 장면의 타깃 위치를 원점 주변으로 옮겨 높이 1.35, 매달린 타깃 시선 보정 +2, BattleCamera 화각 52도를 적용했다. 9:16은 비교용 임시 화면 비율이며 실제 조합판 UI가 가리는 영역까지 검증한 것은 아니다.
- 배경·모델은 무광 색상을 비교하기 위한 Unlit이다. 최종 구미호 조명/머티리얼과 차이가 있다.
