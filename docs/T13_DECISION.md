# T13 중단·연결 실패 처리 — 적용 결정

2026-09-13. 사용자 최신 지시 **“실제로 구현해야할게 얼마나 남았는지 알려주고 그걸 시작해”**에 따라 T13을 실제 구현했다. 착수 시 남은 정식 단계는 T13~T16의4개였다. T13은 중단·실패 처리 보완이며, 이후 단계는 기존 구현의 무결성·성능·사용성 검증과 정리 비중이 크다. 단계 수를 완료율로 계산하지 않는다.

T12의 실제 관측 결과, 빌드18 전달100회 결과, 빌드19 전달100회 미실행을 각각 보존한다. **G5는 NOT_RUN**이다. 이번 구현 착수는 최신 사용자 지시를 따른 것이며 미실행 검사를 PASS로 처리한 것이 아니다. iPhone+iPad 대체 범위는 이미 승인돼 있어 재승인 절차를 추가하지 않았다.

## 실제 바뀐 동작

| 보완 | 적용한 처리 |
|---|---|
| 유효한 상대 응답 감시 | 초기 상태 합의 뒤 정상으로 검증된 상대 게임 응답만 감시 시간을 갱신한다. 송신자·방·세션·인증값·라운드가 다른 응답은 갱신하지 않는다. 기존 연결 기준과 같은8초를 사용한다. |
| 중단·복귀 정리 | 실제 pause를 받으면 원인을 기록하고 입력·미확정 동작·투사체·연결을 정리한다. 복귀 뒤 이전 전투를 자동 재개하지 않고 새 방 연결을 기다린다. focus 변화만으로 종료하지 않는다. |
| 오류 안내·새 연결 | 응답 시간 초과와 시간 만료 패배를 구분한다. 실제 백그라운드·연결 오류별로 수동 새 연결 안내를 보여준다. 로컬 네트워크 권한 거부는 명확한 오류 근거가 있을 때만 안내한다. |

`T10GameSession`에 T13 전용 옵션과 응답 감시를 연결했고, `T10LobbySession`·`T10LobbyController`에 중단 전달·오류 안내를 보완했다. 오류 정리 중 발생하는 연결 종료 콜백이 정리를 중복 실행하지 않도록 처리했다. 명시적으로 켠 Development 진단 외에는 자동 시험·응답 보류가 작동하지 않는다. 이전 프로세스의 진단 명령도 새 실행에 재적용하지 않는다.

별도 `InterruptionBattle.unity` 빌드20을 만들었다. 기존 빌드19 씬·메타와 공용 Config는 보존했고, 양방향 전달·가까운 가장자리 판정·잡을 때 효과·하단 조합·상단 발사는 유지한다. 시작 구슬0, 스태미나100, 생성 비용20, 시간 회복20/3초, 실제 유효 명중 공격자+5도 그대로다.

빌드 진입점은 `C6.Editor.InterruptionBuild.Prepare`, `ExportIOS`, `BuildMac`이며 기본 출력은 `Builds/T13`, 별도 출력은 `C6_T13_OUTPUT_ROOT`로 지정한다. 기존 iOS 네이티브 상태바 처리의 `PatchSources` 알고리즘은 바꾸지 않았다. 적용 대상을 단독 T13 씬까지 명시적으로 허용하고 실제 씬을 영수증에 기록했다. 혼합 씬을 무조건 패치하지 않는다.

Unity 6.0 공식 [OnApplicationPause](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/MonoBehaviour.OnApplicationPause.html)·[OnApplicationFocus](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/MonoBehaviour.OnApplicationFocus.html)는 일반 API 설명으로 참고했다. 설치된6000.5.7f1의 실제 네이티브 적용 근거는 기존 고정 소스 해시·치환 블록·이번 export 영수증이다. 공식 문서를 실기기 실행 증거로 대체하지 않는다.

Unity·URP·패키지를 업그레이드하지 않았다. 사본의 자동 직렬화·빌드 전처리에서 바뀐 `PC_RPAsset`, `Mobile_RPAsset`, `DefaultVolumeProfile`, `UniversalRenderPipelineGlobalSettings`와 새 `SceneTemplateSettings.json`은 이관에서 제외했다. 메타와 기존 설정은 보존한다. 빌드 출처와 제외된 설정 차이는 검증 문서에 명시했다.
