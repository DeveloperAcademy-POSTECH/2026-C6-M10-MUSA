# 현재 박을 4096×4096 투명 PNG로 내보내기

## 사용법

1. Unity에서 Play Mode로 Lab 또는 Hapio 전투에 들어간다.
2. 원하는 만큼 박을 칠한다. 미도색·부분 도색도 가능하며 승리나 100% 완료가 필요하지 않다.
3. 같은 상태를 유지하려면 Unity 상단 Pause를 켠다. Play Mode를 종료하면 현재 도색 상태가 없어질 수 있다.
4. 메뉴 **Hapio → Export Current Gourd PNG (4096)...** 를 선택한다.
5. PNG 저장 위치와 이름을 고른다. 기본 위치는 프로젝트의 `Builds/GourdExports/`이며 Git에서 제외되는 빌드 폴더 아래다. 저장 후 Finder에서 파일을 보여준다.

한 실행 환경에 박이 여러 개 있다면 Hierarchy에서 원하는 박/부모/자식을 선택한다. 선택한 대상에 연결된 `LabGourdPaint`를 우선 사용한다. 선택하지 않았을 때 준비된 박이 하나면 자동 선택하며, 여러 개면 임의로 고르지 않고 안내한다.

## 출력 내용과 경계

- 해상도는 **4096×4096**, 형식은 **RGBA PNG**, 배경은 투명하다. 이미지 뷰어에 따라 투명 부분이 검정으로 보일 수 있다.
- 현재 표시 모델의 방향과 실제 도색·플레이어 무늬·재질 값을 읽는다. 전투 카메라의 시선 방향을 사용하며, 박 전체가 정사각형 안에 들어오도록 여백을 두고 자동으로 맞춘다.
- UI·풍경·게임 스크립트·충돌체를 포함하지 않는다. 독립 Preview Scene에서 메시와 재질만 복사해 렌더링한다. 적용된 Scene 조명도 복사하며, 조명이 없으면 캡처용 기본 방향광을 쓴다.
- 캡처 카메라의 후처리는 끄고, 기기가 지원하는 MSAA(최대4배)를 사용한다. 알파를 보존하고 PNG 가장자리의 검정 번짐을 줄이도록 처리한다.
- 배경/후처리/환경 그림자를 포함하지 않는 단독 렌더이므로, Game View의 주변 환경을 포함한 최종 명암과는 차이가 있을 수 있다.
- 원본 Scene·카메라·게임 설정과 Host 판정 지도를 저장/변경하지 않는다. `PrepareVisualCapture()`는 밀린 시각 도색 작업만 완료한다. 임시 모델·재질·RenderTexture는 성공/실패 모두 정리한다.
- 완성 연출이 원본 박을 잠깐 숨긴 동안에는 다른 각도의 숨은 박을 내보내지 않고 안내한다. 완성 연출 전에 촬영하거나 원본이 다시 보이는 시점에 사용한다. 결과 관람창의 회전 각도를 내보내는 기능은 이번 범위에 없다.
- 4K는 최종 이미지 해상도다. 도색 원본 품질(현재1024×512/2048×1024)을 자동 변경하거나 이미 없는 세부 정보를 추가하지 않는다. 고품질 도색이 필요하면 새 판을 시작하기 전에 DEV에서 고해상도 도색 품질을 올린다.

## 코드 위치

| 파일 | 역할 |
| --- | --- |
| `Assets/Editor/GourdExport/CurrentGourdPngExport.cs` | 메뉴·현재 박 선택·카메라 검색·PNG 저장·Finder 표시 |
| `Assets/Editor/GourdExport/GourdPngCapture.cs` | 메시/재질/프로퍼티 복사·정사각형 프레이밍·URP 렌더 요청·알파 보정·자원 해제 |
| `Assets/Lab/Scripts/Throw/LabGourdPaint.cs` | 읽기 원본: 현재 모델과 실제 도색 맵. 이번 도구 추가로 수정하지 않음 |

모든 새 실행 코드는 `Editor/` 아래에 있으므로 iOS·Mac Player 빌드에 들어가지 않는다. 기존 결과 관람의 완료 조건과 네트워크 규칙도 바꾸지 않는다.

## 확인 기록 — 2026-10-27

초기 구현 작업 폴더의 Unity6000.6.5f1·Metal·설치된URP17.6.0에서 아래 독립 렌더 검사를 실행했다. PR용 `feat/#335-gourd-png-export`를 main에서 분리한 뒤에도 동일한 두 소스 파일의 컴파일과 메뉴 등록을 확인했다.

- 컴파일: 오류 없음. 새 도구 클래스와 메뉴가 Editor에 로드됨.
- 저장된 실제 `WhiteGourd` 프리팹과 게임 도색 셰이더에 3색 부분 도색을 넣은 독립 검사: 4096×4096 RGBA PNG 생성. 투명 배경·불투명 박·다색 도색·안티앨리어싱 가장자리 존재 확인.
- Renderer 전체 및 서브메시별 MaterialPropertyBlock을 사용한 도색 보존 확인.
- 실제 `LabGourdPaint.Attach()`로 초기화한 독립 박의 약7.59% 부분 도색과 고해상도 표현ON 상태에서 `CurrentGourdPngExport.Export()`로4096 PNG 저장 확인. 소스 색칠 셀과Config 보존.
- 원본 Transform·카메라·도색 셀·Config·열린 Scene의 dirty 상태·`RenderTexture.active` 보존 확인.
- 표시 메시 없음·숨겨진 메시·지원 범위 밖 해상도 거부와 임시 RenderTexture 정리 확인.
- PNG를 열어 모델 프레이밍과 부분 도색을 시각 확인.
- 흰색·짙은 회색 배경에 PNG를 합성해 배경 투명도와 외곽 가장자리를 추가 확인.

이 기록은 **독립 렌더 검사**다. 실제 Play Mode에서 메뉴 클릭→저장 대화상자→PNG 파일 생성까지의 전체 검증은 후속 요청에 따라 보류했으며 미실행으로 남긴다. 이 도구는 Editor 전용이므로 iOS 실기기와 Player에서의 파일 저장은 대상이 아니다.
