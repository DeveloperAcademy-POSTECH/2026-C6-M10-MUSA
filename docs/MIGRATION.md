# Unity 프로토타입 조직 저장소 이관 기록

작성일: 2026-09-15. 대상: `DeveloperAcademy-POSTECH/2026-C6-M10-MUSA` 공개 저장소. 작업 브랜치: `feature/unity-prototype`. main 병합은 팀 검토 후 진행한다.

## 원본과 대상의 관계

기존 비공개 C6 프로토타입의 기준 커밋 `66b6dc163c3c8f4f2f1c1212f35734a6bb7bd6ae`(빌드24 코드와 개발 보고서)의 **현재 파일**을 대상 main에서 만든 브랜치에 가져왔다. 서로 다른 두 Git 이력을 합치거나 force push하지 않는다. 원본 프로젝트·과거 커밋·원시 검증 자료는 원래 위치에 보존한다.

대상 기준 main은 `6bf264732f7cd178f53da49841e103413caea762`이며 기존 README의 팀 소개와 `.github/ISSUE_TEMPLATE/`의 최신 팀 양식를 유지한다. 원본 README와 누적 AGENTS는 그대로 복사하지 않고 대상 소개를 유지하는 README와 현재 규칙의 AGENTS를 작성했다.

## 포함한 파일과 공개용 변경

- Unity 소스·테스트·씬·Prefab·Material·Config·.meta, Packages, ProjectSettings, 도구와 Git 속성/제외 규칙을 포함한다.
- 현재 Markdown 개발 문서와 초보자 보고서1~3을 포함한다. 개인 홈경로·서명자·Team ID·연결 주소는 예시 값으로 일반화했다.
- 검증된 원본 기준 Unity 게임 코드·씬·설정·패키지를 유지한다. `Assets/TutorialInfo/Layout.wlt`의 개인 홈경로만 일반적인 개발자 경로로 바꿨다. 게임 실행 로직 변경은 없다.
- 문서의 비공개 저장소 소스 링크는 이관된 파일의 상대 링크로 바꾸었다. 과거 커밋 줄 위치는 당시 snapshot 기준이며 이후 수정 시 함수명을 검색한다.
- 원시 근거/과거 문서 링크는 원본이 공개되지 않음을 표시하고 공개 검증 요약으로 연결한다. 생략한 이미지나 로그를 새로 검증한 자료처럼 대체하지 않는다.
- 팀원이 실제 사용할 빌드 안내는 현재 P4 씬·메뉴·자신의 Apple Team 기준으로 정리한다. 기본 Bundle ID·앱 이름 변경은 별도 개발 작업이다.

## 포함하지 않은 항목

| 항목 | 처리 이유와 보존 |
|---|---|
| 기존 Git 이력 | 독립 저장소의 현재 구현 이관이며 과거 private 커밋을 공개하지 않음 |
| `docs/evidence/` 1,181개 | 기기 로그·서명 검사·개인 경로 등이 섞여 있어 원본 비공개 보존 |
| `docs/history/` 187개 | 과거 문서 snapshot과 개인 환경 기록을 원본에 보존 |
| 원본 README·AGENTS 그대로 복사 | 대상 팀 소개·현재 작업 규칙에 맞춰 공개용 문서 작성 |
| Library·Builds·Logs·서명 자료 | 생성 출력·캐시·원시 자료. 이관할 게임 소스가 아님 |
| 원본 미커밋 설정3개 | 렌더러 자산2개의 직렬화/셰이더 필터 변경과 비활성 씬 순서 변경. 새 검증 증거가 없어 마지막 커밋 기준을 이관하고 원본 변경은 보존 |

프로토타입의 현재 규칙은 Yin/Yang/Combined, 2~5인,2D 연속이동,손떼기3D 투척이다. 팀 소개의 오행·상성·요괴AI·실제방어를 구현했다고 기록하지 않는다.
