# 공개 검증 요약

## 이관 이후 네트워크 수정 · 앱26 (2026-09-15)

추가 패키지 없는 연결 개선은 [L2 구현·실행 기록](L2_CONNECTION_INTEGRATION.md), [L3 게임·다인 회귀](L3_GAME_REGRESSION.md), [L4 핫스팟 확인](L4_HOTSPOT_VALIDATION.md)에 별도로 기록했다. 소스·설정을 대조한 검증 폴더에서 전체 EditMode 1,417개·PlayMode 146개와 Mac 혼합 3/5인 검사를 수행했으며, iOS 앱26 빌드·서명·두 기기 실행도 확인했다. 동일 검사를 단계별로 중복 합산하지 않는다.

핫스팟의 입장·게임 시작·새 방 재입장은 연결 기록, 전달·조합·투척·결과 화면은 사용자 보고로 구분한다. 일반 공유기 Wi-Fi·인터넷 없는 LAN은 **NOT_RUN**, L4 전체는 미완료다. 원시 로그·서명 정보는 공개하지 않는다.

**아래는 파일 이관 당시의 과거 기록**이다. 아래의 ‘새 경로 실행 NOT_RUN’과 빌드24 제한은 당시 판정으로 보존하며, 현재 앱26 범위는 위 후속 보고서를 확인한다.

## 이 문서가 설명하는 증거

2026-09-15 조직 저장소 이관을 위해 기존 개발 기록의 결과를 요약했다. **아래는 원본 프로젝트에서 보고된 실행 범위이며, 이관된 새 폴더에서 새로 실행한 결과가 아니다.** 원시 기기 로그·서명 검사·개인 경로가 포함된 `docs/evidence`와 과거 문서 묶음 `docs/history`는 기존 비공개 저장소에 보존했다. 이 공개 저장소에서는 그 원시 파일을 직접 열어 재검증할 수 없다.

다른 문서의 ‘원본 비공개 자료 — 공개 요약’ 링크는 파일 대체물이나 새 PASS 근거가 아니라 이 제한을 알리는 링크다. 기기 종류·검사 수·실행 범위는 설명하되 개인 서명자·기기 일련번호·연결 주소는 공개하지 않는다.
