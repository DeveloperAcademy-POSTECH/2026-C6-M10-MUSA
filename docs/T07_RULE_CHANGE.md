# T07 · 사용자 생성·Stamina 규칙 변경

2026-09-13 최신 사용자 지시가 기존 통합본의 최초 Raw5 배치·시간 회복 금지보다 우선한다. 통합본 원문과 T06 이전 문서는 보존하며 현재 구현 지시는 이 변경표를 따른다. 아직 구현/시험 완료를 뜻하지 않는다.

| 항목 | 이전 통합본 | 이번 사용자 확정 |
|---|---|---|
| 시작 구슬 | 최초 Tap Raw5 배치 전 빈 상태 | 시작 구슬0개 |
| 최초5의 의미 | Raw5/비용5 특별 배치 | 최대5칸에 해당하는 전체 게이지100을 가득 채워 시작 |
| 내부 Stamina | 최대/시작5 | 최대/시작100, 연속 수치로 계산 |
| Generate | 최초Raw5/비용5, 이후1/1 | 최초부터 항상Raw1개/비용20 |
| 시간 회복 | 없음 | 3초당20(1칸) |
| 유효 명중 회복 | 실제 공격자+1 | 실제 공격자+5 |

초당20/3의 연속 회복으로 구현한다. 이는100단위 게이지에서3초당20이라는 확정 속도를 적용하는 방법이다. 표시만5개의20단위 구간으로 나눌 수 있으며 논리 자원을 정수0~5로 계산하지 않는다. 최대치에서 남은 회복 시간을 쌓아두지 않고, 중단/종료 구간의 시간을 자동으로 따라잡아 회복하지 않는다. 이 시간 처리 방식은 DEMO_ASSUMPTION으로 기록한다.

첫 생성 전용 배치/비용/InitialBatchGenerated 플래그는 이번 규칙에 필요하지 않으므로 만들지 않는다. 비용과 구슬 생성은 Host가 원자적으로 승인하고 실패·중복 요청은 자원/구슬/난수 진행을 바꾸지 않는다. 일반 음양은 Host Seed의50/50 결정이며 거부 요청은 난수를 소비하지 않는다(DEMO_ASSUMPTION).

일반 시작에서 무료 구슬을 공급하지 않는다. 원문 T07의 음5/양5 및 실제 명중 연결 시험용Combined는 명시적인 DEBUG_TEST_MODE·별도 버튼/시험 경로에만 둔다. 일반 생성, 시작 상태와 구분하여 Config·HUD·로그에 표시한다. 원문 T07/AT-04의 최초5배치 관련 시험은 ‘빈 시작/100/매회1개20/5회분의 자원’으로 대체하고 이전 증거는 소급 변경하지 않는다. 보관 상한20·실제 sender/owner·중복/이전 라운드 검증·한 번 피격·한 Config 원칙은 유지한다.

T07만 수행한다. 조합은T08, 정식 Battle/Clock/Reset 및 한 판의 실기기 통합은T09다. 이 문서의 규칙 확정은 구현/빌드/실기기 PASS가 아니다.
