# 스테이지 전투 UI 컴포넌트

Figma `4185:2672`, `4203:1039`, `4203:1589`, `4234:1028`의 UI 부품을 Hapio 전투에 적용한다. Scene·스테이지별 배경·박 모델·카메라·조합대 충돌 프로필은 그대로다. 튜토리얼과 독립 Lab은 기존 UI를 쓴다.

## 구성과 색 전환

- `GameBattleUiTheme` / `Resources/Hapio/UI/BattleUiTheme.asset`: 원본 에셋, 어두운/밝은 밑줄·점령 눈금·깃발, 세 조합대 텍스처, 위치·북·구슬 에셋을 공유한다.
- `GameBattleUiPresentation`: 기존 Battle 바인딩에서 연결한다. 시간·일시정지·스테이지 표제·박 진행률·6칸 스태미나와 캐릭터 프로필을 구성한다. 1스테이지는 어두운 잉크, 2·3은 밝은 잉크이며 조합대는 스테이지별 변형을 쓴다. 조합대는 Figma 4229:3949·4238·4282를 따른다. 402×874 기준 원본 타원 크기는 732.850891×494.996063, 상단 y=459이며 x는 1스테이지 -162, 2·3스테이지 -165다. 원을 화면에 맞춰 축소하지 않고 좌우·아래를 잘라 표시한다.
- `GameUiFrame`: 중앙이 투명한 공용 둥근 스트로크다. 시간/일시정지/진행률/점령률에서 같은 구현을 쓴다.
- `LabDrumMinimap.compactGamePresentation`: Hapio에서만 작은 위치 표시를 사용한다. 기본 모드 3·4·5인 배치, 팀전 세로 2인 배치와 3:3 삼각형 배치(Figma `5457:7989`, `5457:8087`)를 지원한다. 3:3에서는 내 자리가 아래, 다음 팀 P번호가 왼쪽 위, 나머지 동지가 오른쪽 위에 표시된다. 같은 팀만 표시하는 기존 필터와 북 소유자·전달 애니메이션은 재사용한다. 스토리는 캐릭터 초상(원 지름 21, 북이 도착하면 그 자리 초상을 숨기고 태극을 12% 크게 표시), 땅따먹기는 #785 이전의 팀 마커와 P번호(원 지름 24)를 표시한다. DEV99의 저장된 기본 50%에서 새 에셋의 100% 크기가 되도록 표현 배율만 보정한다.
- `BattleOrbAppearance.asset`: 기존 구슬 표현 프로필을 복사하고 오행 구슬과 생성 북 스프라이트만 바꾼다. 음·양 및 아이템 연출은 보존한다. 런타임 LabConfig 복사본의 비직렬화 표현 override로 보드와 투사체에 공통 적용하며 원본 LabConfig와 도색 팔레트는 변경하지 않는다.

토큰 원본과 적용 규칙은 [COLOR_SYSTEM](COLOR_SYSTEM.md), 에셋별 원본은 `Assets/Hapio/Art/UI/Battle/README.md`를 따른다. 조합대는 별도 RawImage로 구슬 합성 이미지 아래, 스태미나·캐릭터 프로필 뒤에 둔다. 기존 OrbBoardPlate의 Transform·메시·물리 프로필은 유지하고 정상 합성 중에는 그 Renderer를 숨긴다. 또한 입력 카메라는 동일 객체·투영을 입력 계산에 유지하면서 별도 한지 배경을 덧그리는 화면 패스만 끈다. `GameBoardBackgroundContinuation`이 기존 스테이지 카메라의 시점·투영을 아래로 연장해 PNG 투명 영역에 같은 배경을 표시한다. 원본 전투 카메라의 viewport/FOV/입력 투영은 바꾸지 않는다. 합성을 사용할 수 없으면 기존 판 렌더러를 유지한다. 원본 2× 합성 에셋의 투명 여백 1.5 단위를 보정하여 배치한다.

새 에셋을 임포트할 때는 `Hapio > Upgrade Battle UI Components`를 사용한다. 이 메뉴는 Scene을 저장하거나 환경 배경을 교체하지 않는다.

## 기존 동작 연결

#785의 [캐릭터 컴포넌트](https://www.figma.com/design/wW7ny7lNQ4DXNJ4kD46AuR/?node-id=5573-4233)와 [전투 화면](https://www.figma.com/design/wW7ny7lNQ4DXNJ4kD46AuR/?node-id=5548-6617)에 맞춰 구미호·야광귀·지귀의 인게임 프로필은 P1 불이, P2 묵이, P3 솔이, P4 금옥, P5 만복이다. 좌우 프로필은 이름 앞뒤에 방향을 붙인다. 자리 선택 UI와 실제 팀·자리 배정은 기존 흐름을 사용한다.

땅따먹기(2:2·3:3·DEV 솔로)는 캐릭터 프로필을 쓰지 않고 #785 이전 HUD를 그대로 쓴다. 내 표시와 좌우 이웃은 청/홍 팀 배지(45×47, 이웃 y 472), 하단은 파란 6칸 스태미나 줄(241×39)과 스테이지별 테두리, 미니맵은 팀 마커다. 스태미나 부족 연출도 예전 흔들림·커짐을 쓴다(`LiftGaugeMode` 끔). `GameBattleUiPresentation.BuildTeamHud`가 이 배치를 만든다.

402×874 기준 좌우 프로필의 y는 475, 하단 바의 y는 773이다. 하단 바는 불이 빨강, 솔이 초록, 묵이 파랑, 금옥 노랑, 만복 갈색의 Figma 배경·프로필·이름 레이어와 5 Orbs Color/100 및 300(금옥은 400) 게이지를 사용한다. LabHud가 기존 스태미나 값을 갱신하고, 부족 효과는 같은 Image의 부모인 `Stamina Cells`만 세로로 흔들고 확대한다. 가로 위치와 폭을 고정해 옆 이름 영역을 침범하지 않는다. 이름·프로필·바 배경은 별도 형제 레이어에 둔다. 기존 부족 경고와 화면 가장자리 표시도 재사용한다. 초상과 패널 원을 동일한 기준점으로 배치한다. Figma에서 고해상도로 내보낸 PNG는 `Resources/Hapio/UI/BattleCharacters`에 있다.

일시정지는 기존 GameSession 라우팅을 유지한다. 점령 막대의 점유율·피버와 팀 고리는 LabTeamBar가 관리한다. 스태미나 칸 프레임·패널과 프로필은 기존 구슬 합성 위계의 직접 자식으로 유지한다. BottomHudBackground의 물리용 경계는 유지한다.

실행한 검사는 [VALIDATION](VALIDATION.md)의 #785 항목을 따른다.

## 땅따먹기 전투

2:2와 3:3은 Figma 4229:5583·4229:7267의 밝은 표제와 점령 막대, 야광귀 배경·조합대을 사용한다. `GameStageBackgrounds.PresentationStage`가 전투 UI와 배경에 동일한 2번 표현 변형을 선택한다. 경기의 스테이지 번호와 요괴 규칙은 별도로 관리한다. 조합대 투명 영역에는 기존 배경 연장 카메라의 화면을 표시한다.

땅따먹기는 캐릭터 초상을 쓰지 않는다(2026-11-17, #785 이전 HUD로 되돌림). 좌우와 하단은 청/홍 팀 배지(팀 안 P번호)이고 미니맵은 팀 마커와 P번호다. 2:2는 42px 간격, 3:3은 26px 간격이며 각각 Figma 연결선 에셋을 쓴다. 북이 도착하면 해당 자리의 마커와 번호를 숨기고 태극을 표시한다. 스태미나 부족 연출의 색(빨간 층·가장자리·경고 글자)은 스토리와 같은 `StaminaFeedbackProfile`을 쓰므로 #788에서 조정한 색이 땅따먹기에도 적용된다.
