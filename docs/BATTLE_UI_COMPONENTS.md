# 스테이지 전투 UI 컴포넌트

Figma `4185:2672`, `4203:1039`, `4203:1589`, `4234:1028`의 UI 부품을 Hapio 전투에 적용한다. Scene·스테이지별 배경·박 모델·카메라·조합대 충돌 프로필은 그대로다. 튜토리얼과 독립 Lab은 기존 UI를 쓴다.

## 구성과 색 전환

- `GameBattleUiTheme` / `Resources/Hapio/UI/BattleUiTheme.asset`: 원본 에셋, 어두운/밝은 밑줄·점령 눈금·깃발, 세 조합대 텍스처, 스태미나 테두리 색, 위치·북·구슬 에셋을 공유한다.
- `GameBattleUiPresentation`: 기존 Battle 바인딩에서 연결한다. 시간·일시정지·스테이지 표제·박 진행률·6칸 스태미나·내 P 표시를 구성한다. 1스테이지는 어두운 잉크, 2·3은 밝은 잉크이며 스태미나 테두리와 조합대는 스테이지별 변형을 쓴다. 조합대는 Figma 4229:3949·4238·4282를 따른다. 402×874 기준 원본 타원 크기는 732.850891×494.996063, 상단 y=459이며 x는 1스테이지 -162, 2·3스테이지 -165다. 원을 화면에 맞춰 축소하지 않고 좌우·아래를 잘라 표시한다.
- `GameUiFrame`: 중앙이 투명한 공용 둥근 스트로크다. 시간/일시정지/진행률/점령률/스태미나에서 같은 구현을 쓴다.
- `LabDrumMinimap.compactGamePresentation`: Hapio에서만 작은 위치 표시를 사용한다. 기본 모드 3·4·5인 배치, 팀전 세로 2인/3인 배치를 지원한다. 같은 팀만 표시하는 기존 필터와 북 소유자·전달 애니메이션은 재사용한다. 피그마의 예시 P번호와 달라도 실제 게임의 청/홍 팀 번호를 표시한다. DEV99의 저장된 기본 50%에서 새 에셋의 100% 크기가 되도록 표현 배율만 보정한다.
- `BattleOrbAppearance.asset`: 기존 구슬 표현 프로필을 복사하고 오행 구슬과 생성 북 스프라이트만 바꾼다. 음·양 및 아이템 연출은 보존한다. 런타임 LabConfig 복사본의 비직렬화 표현 override로 보드와 투사체에 공통 적용하며 원본 LabConfig와 도색 팔레트는 변경하지 않는다.

토큰 원본과 적용 규칙은 [COLOR_SYSTEM](COLOR_SYSTEM.md), 에셋별 원본은 `Assets/Hapio/Art/UI/Battle/README.md`를 따른다. 조합대는 별도 RawImage로 구슬 합성 이미지 아래, 스태미나·P 표시 뒤에 둔다. 기존 OrbBoardPlate의 Transform·메시·물리 프로필은 유지하고 정상 합성 중에는 그 Renderer를 숨긴다. 또한 입력 카메라는 동일 객체·투영을 입력 계산에 유지하면서 별도 한지 배경을 덧그리는 화면 패스만 끈다. `GameBoardBackgroundContinuation`이 기존 스테이지 카메라의 시점·투영을 아래로 연장해 PNG 투명 영역에 같은 배경을 표시한다. 원본 전투 카메라의 viewport/FOV/입력 투영은 바꾸지 않는다. 합성을 사용할 수 없으면 기존 판 렌더러를 유지한다. 원본 2× 합성 에셋의 투명 여백 1.5 단위를 보정하여 배치한다.

새 에셋을 임포트할 때는 `Hapio > Upgrade Battle UI Components`를 사용한다. 이 메뉴는 Scene을 저장하거나 환경 배경을 교체하지 않는다.

## 기존 동작 연결

양옆 플레이어 번호는 조합대 위쪽 테두리에 걸쳐 표시한다. 402×874 기준으로 구미호·야광귀·지귀·땅따먹기 모두 좌우 번호 영역의 상단을 472에 두고, 좌우 중심은 각각 14.5와 387.5에 둔다. 하단의 내 번호와 6칸 스태미나는 9 디자인 단위 간격을 두고 화면의 가로 중앙에 함께 정렬한다.

시간/박 진행률/스태미나 값과 P번호는 LabHud가 갱신한다. 일시정지는 기존 GameSession 라우팅을 유지한다. 점령 막대의 점유율·피버와 팀 고리는 기존 LabTeamBar가 관리한다. Hapio 땅따먹기의 깃발은 Figma 배치에 맞춰 막대 양 끝에 둔다. 전투 입력·충돌·전달·네트워크 설정/프로토콜은 추가하지 않는다. 스태미나와 P 표시를 기존 구슬 합성 위계의 직접 자식으로 유지한다. BottomHudBackground의 물리용 경계는 바꾸지 않는다.

실행한 검사는 [VALIDATION](VALIDATION.md)의 2026-11-08 전투 UI 기록을 따른다.

## 땅따먹기 전투

2:2와 3:3은 Figma 4229:5583·4229:7267의 밝은 표제와 점령 막대, 야광귀 배경·조합대·스태미나 색을 사용한다. `GameStageBackgrounds.PresentationStage`가 전투 UI와 배경에 동일한 2번 표현 변형을 선택한다. 경기의 스테이지 번호와 요괴 규칙은 별도로 관리한다. 조합대 투명 영역에는 기존 배경 연장 카메라의 화면을 표시한다.

내 번호와 조합대 양옆 번호에는 Figma `4850:7019`의 청팀·홍팀 에셋을 사용한다. 해당 팀 안에서 P1부터 표시한다. 오른쪽 위치 표시는 같은 팀의 실제 P번호를 사용한다. 2:2는 42px 간격, 3:3은 26px 간격이며 각각 Figma 연결선 에셋을 쓴다. 북이 도착하면 해당 자리의 마커 위를 북 아이콘으로 바꾼다.
