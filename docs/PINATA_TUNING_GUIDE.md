# 피냐타 흔들림 실험 가이드

브랜치: `experiment/yetii-pinata-juice`
기준 main: `26d0b380`
가져온 원본: `experiment/yetii-hanging-target`의 `27535389`

## 가져온 기능

- 천장·줄·고정점·표적 본체와 실제 피격 Collider가 함께 움직이는 매달린 표적
- Host가 확정한 실제 명중 속도에 따른 흔들림과 짧은 색 변화
- 세션에 속한 클라이언트로 명중 충격 전달, 새 라운드 흔들림 초기화
- 표적을 보여주는 카메라 방향과 바닥 여유 공간

## 가져오지 않은 변경

이전 브랜치의 구슬 Sphere 표현, 생성 초기 속도, 감속·정지 기준 조정, 솔로 좌우 반발, 조합대 카메라 영역 조정은 옮기지 않았다. 최신 main의 구슬 아트, 물리, 2~5인 방과 공유 DEV 설정 구현을 유지했다. LabConfig 원본 수치도 main 그대로다.

## 직접 수치 조절하기

1. `Assets/Lab/Scenes/Lab.unity`를 연다.
2. **C6 Lab → Pinata → Select Target** 또는 Hierarchy의 **Pinata Target**을 선택한다.
3. Inspector의 **Lab Hanging Target → 피냐타 흔들림 실험**에서 아홉 값을 직접 입력한다. 약·중·강 프리셋은 없다.

| 항목 | 기본값 | 입력 범위 | 효과 |
| --- | ---: | ---: | --- |
| 밀리는 힘 | 2.4 | 0~20 | 같은 충돌 속도에서 표적을 미는 충격 배율 |
| 흔들림 감쇠 | 1.15 | 0~20 | 높을수록 빨리 멈춤. 0은 감쇠 없음 |
| 최대 흔들림 각도 | 24 | 1~75도 | 수직에서 벗어날 수 있는 최대 각도 |
| 원래 위치로 돌아오는 힘 | 13 | 0~100 | 높을수록 복원력이 커짐. 0은 복원력 없음 |
| 줄 길이 | 0.85 | 0.1~8 | 고정점부터 표적 상단까지의 월드 단위 길이 |

일반적인 충격은 설정 배율에 따라 달라지며, 아주 큰 충격은 안전 상한으로 제한된다. 이 상한 근처에서는 밀리는 힘을 높여도 차이가 작아질 수 있다.

4. Play를 누른다. **같은 충격으로 반응만 확인**을 누르면 기존 흔들림을 초기화하고 매번 동일한 방향·속도(표적 기준 6, 0, -9)의 충격을 준다. HP와 스태미나를 바꾸지 않는다.
5. 밀리는 힘만 바꿔 5회씩 비교하고 나머지 세 값은 유지한다. 실행 중 값 변경은 다음 물리 프레임부터 반영된다.
6. 실제 투척은 **DEV → START SOLO**로 시작하고 구슬을 생성·조합해 확인한다. 반응 미리보기와 실제 명중은 구분해 기록한다.
7. Play 중 바꾼 값은 Play 종료 시 되돌아간다. 원하는 값을 기록한 뒤, 종료 상태에서 다시 입력하고 **Scene을 저장**하면 다음 실행에도 유지된다.

피냐타 설정은 표적 컴포넌트의 로컬 Scene 설정이며 현재 39개 DEV 공유 설정에는 포함하지 않았다. 다인 실험에서는 참가자들이 같은 Scene 설정을 사용해야 한다. Inspector 반응 미리보기는 로컬에서만 작동한다.

## 검증

Unity 6000.6.5f1의 별도 검증 복사본에서 실행했다. 복사본은 정상 도메인·Scene 재로드를 사용하고 원본 Editor 설정은 유지했다.

- EditMode: 26/26 Passed.
- PlayMode: 30/31 Passed. 추가한 피냐타 검사 3/3과 저장 Scene의 생성·조합·실제 명중 후 흔들림 검사가 통과했다.
- 실패: `SavedDeveloperPanelCreatesAndRetunesTwoPlayerHostLobby`. 변경 전 `26d0b380` main 복사본에서도 27/28, 같은 검사·같은 방 생성 assert가 실패했다. 기존 main의 검사 실패와 구분한다.
- 원본 Editor에서 Pinata Target의 네 숫자 입력칸 표시를 확인했다.
- 다인 흔들림 동기화·iOS 실기기·Mac 앱 재빌드와 사용자의 직접 플레이 체감은 NOT_RUN.

원시 XML과 실행 로그는 공개 저장소에 포함하지 않는다.

## 탄력 있는 흔들림과 줄 길이

- 시작 비교값: 감쇠 1.15 → 0.65, 복원력 13 → 25. 한 번에 한 항목씩 바꿔 동일 충격으로 비교한다. 밀리는 힘은 진폭을 바꾸므로 먼저 그대로 둔다.
- 줄 길이는 Play 중에도 수정할 수 있다. 줄·고정점·천장·피격 본체·시각 Mount를 함께 갱신하며 정지 상태의 표적 중심은 유지한다. 같은 각도에서 줄이 길면 표적의 이동 폭이 커진다. 아주 긴 줄은 천장이 화면 밖으로 나갈 수 있다.
- 현재 흔들림은 조절 가능한 감쇠 진동 모델이다. 줄 길이에 맞춰 복원력이 자동 변경되지는 않는다. 몸체가 찌그러지는 말랑한 변형 효과는 포함하지 않는다.

줄 길이 추가 후 피냐타 PlayMode 검사 4/4 Passed. 줄 길이 2에서 실제 줄 끝과 본체 상단의 연결, 정지 중심 유지, 흔들림 후 초기화를 확인했다.

## 위아래 탄성 움직임 — 2026-10-12

참고 영상의 위아래 반동을 비교하기 위해, 매달린 표적에 조절 가능한 스프링 움직임을 추가했다. 실제 명중과 Inspector의 동일 충격 미리보기 모두 적용된다. 기존 좌우 흔들림과 함께 작동한다. 줄이 늘어나고 줄 끝·표적 본체·실제 Collider·시각 Mount가 함께 움직이며 천장 고정점은 고정된다. 줄의 곡선 표현과 몸체 변형은 이번 변경 범위가 아니다.

| Inspector 항목 | 기본값 | 범위 | 효과 |
| --- | ---: | ---: | --- |
| 위아래 튕기는 힘 | 0.18 | 0~2 | 명중 속도에 비례해 아래쪽으로 주는 충격 배율 |
| 위아래 복원력 | 45 | 0~100 | 기본 줄 길이로 돌아오는 힘. 높을수록 빠른 반동 |
| 위아래 감쇠 | 3 | 0~20 | 위아래 진동을 멈추는 정도. 낮을수록 오래 진동 |
| 최대 늘어나는 거리 | 0.5 | 0~3 | 추가 늘어남의 거리. 0이면 위아래 움직임 비활성화 |

위로 돌아올 때는 줄이 잠깐 짧아지는 반동도 허용하되, 기본 줄 길이의 45%와 최대 늘어남의 절반 이내로 제한한다. 이는 게임 느낌을 위한 탄성 모델이며 실제 로프의 강체 물리 해석은 아니다.

실험은 기본값에서 동일 충격 미리보기 5회 → 위아래 감쇠만 3에서 1.5로 변경 → 다시 5회 비교 순서로 시작한다. 최대 늘어남 0으로 기존 좌우 흔들림과 비교할 수 있다. Play 중 값은 종료 시 되돌아가므로 기록 후 종료 상태에서 입력하고 Scene을 저장한다.

코드 반영 전 사용자가 Play에서 조절한 회전 실험값 기록: 밀리는 힘 20, 감쇠 1, 최대 각도 75, 복원력 12, 줄 길이 3. 이 값은 자동으로 Scene에 저장하지 않았다.

검증: 별도 복사본의 PlayMode 33/34. 피냐타 검사 6/6, 실제 명중 연결 검사가 통과했다. 유일한 실패는 변경 전 main에서도 확인한 `SavedDeveloperPanelCreatesAndRetunesTwoPlayerHostLobby`이다. 위아래 반동·감쇠·초기화·줄과 Collider의 연결·반복 타격의 범위 제한·최대 늘어남 0의 비활성화를 확인했다. 다인 동기화와 실기기 체감은 별도 검증이다.

이번 탄성 변경의 EditMode 26/26 Passed.
