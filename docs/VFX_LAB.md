# VFX 녹화용 실험실 (#610, #741)

디자이너에게 넘길 VFX 에셋 시트를 만들기 위해, 혼자 플레이로는 녹화하기 어려운 장면을 실제 게임 화면 그대로 바로 띄우는 Editor 창이다. 빌드에는 들어가지 않고 게임 규칙/DEV 설정/접속 버전을 바꾸지 않는다.

## 여는 법

1. Unity 메뉴 **Hapio > VFX 실험실**
2. 라운드(1R 구미호 / 2R 야광귀 / 3R 지귀)를 고르고 **게임 화면 열기** → Home에서 혼자 시작까지 저절로 간다.
3. 전투가 시작되면 버튼이 켜진다. Game 창을 화면 녹화한다.
4. Test Runner를 돌릴 때는 이 창을 닫는다.

## 창 구성 (#741)

- **공통 기믹 (모든 라운드):** 박 폭탄 / 넘기기 막기 / 박 폭탄 바로 터뜨리기, 남은 30초 알림(징 / 북 / 징 다음 북).
- **라운드별 기믹:** 기믹마다 묶고, 그 안을 **예보 / 진행 / 파훼 / 보상 / 처벌** 줄로 나눈다. 지금 상태에서 누를 수 없는 버튼은 꺼진다.
  - 2R: Y1 섬광 / Y2 콤보 · Y3 BIG · SMALL / Y5 야광귀 피버
  - 3R: J1 연기 → 검은 구슬 / J2 부적 → J4 물 폭포 · J3 실패 / 지귀 피버

## 버튼이 하는 일

- **예고부터 / 예고 없이 바로:** 시간표가 그 기믹을 꺼낼 때와 같은 길로 시작한다. "예고 없이"는 예보 단계만 건너뛴다. 다른 기믹이 진행 중이거나 보상 / 벌칙이 남아 있으면 꺼진다. 지귀는 연기 / 부적을 골라 시작하고, 시간표의 다음 차례가 다른 종류면 한 칸 건너뛴다.
- **다 흔든 것으로 해제 / 다 닦은 것으로:** 모든 화면에서 흔들기 / 닦기를 끝낸 것으로 하고, 실제 게임과 같은 해제 연출(대사 → 보상)로 간다.
- **다음 칸 색 구슬 받기 / 다른 색 구슬 받기:** 콤보가 원하는 색, 또는 틀린 색의 결합 구슬을 내 판에 놓는다. 직접 던져 맞히면 실제 게임처럼 판정한다.
- **한 칸 맞히기 / 남은 칸 다 맞히기:** 내가 맞힌 것으로 처리한다. 다 맞히면 게임과 같은 BIG 보상이 모두에게 걸린다.
- **틀린 색 한 번 / 바로 실패:** 틀린 색 판정(첫 콤보는 봐주기 → 하트 깨짐), 또는 시간 끝 실패(SMALL).
- **BIG / SMALL 바로 끝내기:** 남은 보상 / 벌칙 시간을 0으로 한다.
- **피버 바로 시작:** 시간표 방해가 끝나는 때(100초)를 지금으로 당긴다. Host 규칙과 화면 시각이 같은 순간을 본다. 실험실이 당긴 판(session + round)에만 쓴다.
- **가짜 자리 수:** 진짜 공용 부적의 자리 아이콘에 가짜 자리를 더한다(화면만, `LabJigwiScreenPresentation.VfxLabFakeSeats`). 부적이 시작되고 0.6초 간격으로 켜지고, 내가 마지막으로 다 쓰면 실제 완성 연출이 나온다. 판정과 스냅샷은 그대로다.
- **박 폭탄 바로 터뜨리기:** 내 판에 잠긴 박 폭탄의 도화선을 다 탄 것으로 한다.
- **30초 알림:** 화면 / 소리 / 진동만 띄운다. 남은 시간과 LabConfig는 그대로다.
