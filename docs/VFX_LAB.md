# VFX 녹화용 실험실 (#610)

디자이너에게 넘길 VFX 에셋 시트를 만들기 위해, 혼자 플레이로는 녹화하기 어려운 장면을 실제 게임 화면 그대로 바로 띄우는 Editor 창이다. 빌드에는 들어가지 않고 게임 규칙/DEV 설정/접속 버전을 바꾸지 않는다.

## 여는 법

1. Unity 메뉴 **Hapio > VFX 실험실**
2. 라운드(2R 야광귀 / 3R 지귀)를 고르고 **게임 화면 열기** → Home에서 혼자 시작까지 저절로 간다.
3. 전투가 시작되면 버튼이 켜진다. Game 창을 화면 녹화한다.
4. Test Runner를 돌릴 때는 이 창을 닫는다.

## 버튼이 하는 일

- **콤보 바로 시작:** 시간표가 콤보 차례를 꺼낼 때와 같은 길로 COMBO 3/2/1 예고부터 시작한다. 섬광/콤보 진행 중이거나 보상/벌칙이 남아 있으면 안 된다.
- **다음 칸 색 구슬 받기:** 콤보가 다음에 원하는 속성의 결합 구슬을 내 판에 놓는다. 직접 던져 맞히면 실제 게임처럼 칸이 체크된다.
- **남은 칸 바로 맞히기:** 남은 칸을 내가 맞힌 것으로 처리해 성공시키고, 게임과 같은 BIG 보상이 모두에게 걸린다.
- **오색구슬 받기:** 섬광 흔들기 없이 오색구슬을 빈자리만큼 놓는다.
- **피버 바로 시작:** 시간표 방해가 끝나는 때(100초)를 지금으로 당긴다. Host 규칙(`LabModel.VfxLabStartYaguangFever`)과 화면 시각(`LabNetwork.YaguangFeverElapsed`)이 같은 순간을 본다. 실험실이 당긴 판(session + round)에만 쓴다.
- **가짜 자리 수:** 진짜 공용 부적의 자리 아이콘에 가짜 자리를 더한다(화면만, `LabJigwiScreenPresentation.VfxLabFakeSeats`). 부적이 시작되고 0.6초 간격으로 차례로 켜지고, 내가 마지막으로 다 쓰면 실제 완성 연출이 나온다. 판정과 스냅샷은 그대로다.
- **지귀 기믹 고르기 (Play 전):** 기본 시간표 / J1 연기만(B Test Only) / J2~J4 부적만(A Test Only). LabConfig 값을 직접 켜고 끈다. 연기/부적은 4초부터 17초마다 나온다. 녹화가 끝나면 기본 시간표로 돌리고, 이 값은 커밋하지 않는다.
