# 모바일 구슬 조작과 화면 방향 (#310)

이 문서는 README의 모바일 조작 설명을 옮긴 유지보수 안내다.
현재 코드의 연결과 설정을 설명하며, 새 기능이나 실행 검증 결과를 추가하지 않는다.
Hapio와 Lab의 기존 전달·조합·전투 규칙은 그대로 사용한다.

## 안쪽 구간에서 구슬 전달

1. 구슬을 잡고 화면 좌우 안쪽의 전달 구간으로 바깥 방향으로 끈다.
2. 구슬 본체도 해당 구간에 도착하면 작은 화살표가 전달 준비 방향을 표시한다.
3. 손을 놓으면 기존 Host 승인 경로로 옆 플레이어에게 전달을 요청한다.

잠시 들고 멈춰도 전달 준비를 유지한다. 안쪽으로 되돌리거나 위로 투척 방향을 바꾸면 해제한다.
손가락만 구간에 도착했다고 본체를 순간 이동시키지는 않는다.
직접 음·양 구슬을 겹치는 조합이 안쪽 전달 보조보다 우선한다.
전달 차단, 2:2 외벽과 Host의 소유권 확인을 우회하지 않는다.
움직이는 구슬의 실제 화면 가장자리 통과도 기존 물리 전달 경로를 유지한다.

## 가장자리에 머문 구슬의 안쪽 보정

좌우·하단에서 거의 멈춘 일반 구슬은 기본 약 0.3초 뒤 다시 잡기 쉬운 안쪽으로 부드럽게 이동한다.
위치를 즉시 바꾸는 대신 속도를 부여하므로 기존 충돌과 곡선 경계를 사용한다.
다음 경우에는 자동 보정으로 이동을 대신하지 않는다.

- 드래그 중이거나 전달·투척·조합 응답을 기다리는 구슬.
- 정체 속도 조건을 넘거나 바깥 방향으로 이동해 물리 전달 중인 구슬.
- 북, 폭탄, 여우불과 도착·폭발 처리 중인 구슬.
- 입력 차단·시뮬레이션 대기 등으로 조합판을 조작할 수 없는 상태.

보정 중 접촉은 일반 충돌 조합과 구분하여, 자동 보정이 새 조합을 일으키지 않도록 한다.
실제 터치가 구슬 본체에 닿으면 다른 구슬의 확대된 보조 터치 범위보다 우선한다.

## Inspector 설정

전투 Scene의 `OrbBoard > LabOrbBoard > Screen-edge controls (#310)`에서 조절한다.
`Enabled`를 끄면 이 로컬 조작 보조를 비활성화한다.

| 설정 | 기본값 | 단위·역할 |
| --- | --- | --- |
| `Transfer Inset` | 36 | 전달 구간의 안쪽 폭 |
| `Minimum Drag` | 12 | 전달 의도를 만드는 최소 가로 이동 |
| `Turn Back Tolerance` | 4 | 안쪽으로 되돌릴 때 전달 준비를 취소하는 거리 |
| `Minimum Grip Radius` | 22 | 작아진 구슬도 잡기 위한 최소 보조 터치 반지름 |
| `Target Padding` | 4 | 안쪽 보정 목표와 구슬 사이 추가 여백 |
| `Bottom Padding` | 16 | 하단 곡선·안전 영역에서 추가 확보할 여백 |
| `Rest Delay` | 0.3초 | 정체 후 보정 시작까지의 대기 |
| `Rest Speed` | 0.035 | 정체 판정 속도, 보드 폭/초 |
| `Nudge Speed` | 0.18 | 안쪽으로 밀어주는 최고 속도, 보드 폭/초 |

위 표의 거리·반지름 6개 값은 **가로 390 기준 UI 단위**다.
실제 화면·카메라 크기에 맞춰 환산하며, 전달 구간과 하단 목표는 화면의 안전 영역도 고려한다.
속도는 픽셀/초가 아닌 보드 폭/초다. 예를 들어 0.18은 1초에 보드 폭의 18%에 해당한다.
이 값들은 로컬 조작 보조이며 공유 게임 규칙이나 통신 버전을 변경하지 않는다.

## 세로 고정과 시스템 제스처

실제 iOS Player는 정방향 세로로 고정하고 가로·거꾸로 세로 회전을 허용하지 않는다.
Editor와 Mac Player의 화면 방향에는 이 iOS 전용 설정을 적용하지 않는다.

연결이 유지되고 입력 가능한 전투 중에만 좌우·하단 시스템 제스처를 유예한다.
로비·일시정지·시작 준비/카운트다운·결과·입력 차단·앱 비활성 상태에서는 유예를 해제한다.
앱 복귀 시에는 현재 상태에 맞게 다시 적용한다. 네트워크의 중단·재개 정책을 바꾸지는 않는다.
이 기능은 실수로 홈으로 나가는 일을 줄이며, 홈 이동을 완전히 차단하지 않는다.

Hapio와 Lab의 iOS 내보내기는 세로 방향과 전체 화면 설정을 공통 검사한다.
빌드 시 제스처 유예는 `None`, `Hide Home Button`은 OFF이며, 전투 중 유예는 런타임이 관리한다.

## 수정할 때 확인할 연결

- `Assets/Lab/Scripts/Orb/LabOrbBoard.EdgeControls.cs`: 위 설정, 전달 의도와 안쪽 보정.
- `Assets/Lab/Scripts/Orb/LabOrbBoard.cs`: 본체 터치 우선 선택, 직접 조합 뒤 전달 처리.
- `Assets/Lab/Scripts/UI/LabMobilePresentationPolicy.cs`: 세로 고정과 전투 상태별 제스처 유예.
- `Assets/Editor/Bootstrap/LabMobileBuildValidation.cs`: iOS 설정과 내보낸 Info.plist 검사.

검사할 때는 안쪽 전달·잠시 정지·되돌림·직접 조합 우선·정체 보정 제외 조건을 구분한다.
iOS에서는 회전, 전투/메뉴의 하단 제스처, 앱 복귀를 별도로 확인한다.
자동 검사나 컴파일 통과를 실기기 조작 통과로 간주하지 않는다.
실제 수행 환경·결과·미실행 범위는 [검증 기록](VALIDATION.md)의 해당 작업 절을 따른다.
