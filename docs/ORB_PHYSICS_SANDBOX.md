# 구슬 물리 조절용 씬

조합대와 음·양 구슬을 미리 보면서 배치하고, Play 중에는 마우스로 잡고 밀어 놓으며 물리값을 조절하는 개발용 씬이다. 기존 P4 게임이 사용하는 `LocalOrbPhysicsBoard`와 공용 `ScreenLayoutConfig`의 일곱 값을 사용한다.

## 시작하기

1. Unity에서 `C6 > Physics Sandbox > Open Tuning Scene`을 선택한다.
2. `Assets/_Project/HapioMVP/PhysicsSandbox/OrbPhysicsSandbox.unity`가 열리면 Hierarchy의 **Orb Physics Tuning**을 선택한다. Play 전에도 두 조합대와 구슬 배치를 볼 수 있다.
3. Play를 누르고 **Game** 창에서 구슬을 마우스로 잡아 움직인 뒤 놓는다. 움직이는 구슬을 다시 잡으면 캐치하는 느낌을 확인할 수 있다.
4. **Orb Physics Tuning**의 Inspector에서 값을 바꾸고 다시 던져본다. Inspector 우측 위 자물쇠를 잠그면 Game 창을 조작하는 동안 선택을 유지하기 쉽다.
5. 만족한 값은 Inspector의 저장 기능으로 공용 Config에 저장한다. Play 종료 전에 저장한다.

Scene 창의 이동 도구는 배치를 편집하는 도구다. 충돌·미끄러짐·손떼기 속도는 Play 중 Game 창에서 확인한다.

## 아이폰 Unity Remote 연결

사용자가 선택한 방식은 **아이폰 터치 → Mac에서 실행 중인 게임 → Mac Inspector로 조절**이다. iOS 앱 빌드를 만들지 않는다.

1. 아이폰에 Unity 공식 **Unity Remote 5** 앱을 설치하고 실행한다.
2. 데이터 전송이 가능한 USB 케이블로 Mac에 연결한다. 아이폰 잠금을 해제하고, 기기에 표시되는 신뢰 확인은 사용자가 직접 처리한다.
3. Unity의 `C6 > Physics Sandbox > Unity Remote Settings`를 연다. `Project Settings > Editor > Unity Remote > Device`에서 연결한 iPhone을 선택한다. 보이지 않으면 앱 실행/USB 연결을 먼저 확인한다.
4. Game 창을 세로 iPhone 비율(예: 390×844 또는 실제 기기 비율)로 맞춘 뒤 튜닝 씬에서 Play를 누른다.
5. 아이폰에서 구슬을 잡고 놓는다. Mac Inspector의 **최근 입력**, **터치 입력 수**가 바뀌는지 확인한다. Mac에서는 수치만 조절한다.

Remote가 전송하는 터치는 기존 Input System의 Touchscreen 경로로 받는다. 물리는 Mac에서 실행되고 화면이 스트리밍되므로 Remote 지연은 실제 iPhone 앱 성능과 다를 수 있다. 최종 손맛은 이후 기기 빌드에서 확인한다.

공식 안내: https://docs.unity3d.com/6000.0/Documentation/Manual/UnityRemote5.html

## 실제 조합대 영역과 두 화면 보기

- 기본은 **실제 게임 조합대 영역 ON**, **좌우 포탈 OFF**다. Play 시 공용 Config의 상하 비율, Safe Area, 게임의 390×844 CanvasScaler 및 연결 후 144포인트 푸터를 반영해 구슬이 움직일 영역을 계산한다. 합체·공격·로비는 실행하지 않는다.
- `실제 게임 조합대 영역`을 끄면 두 영역을 한 화면에서 보는 개요 모드다. 물리 단위는 각 영역 너비 기준으로 같다.
- `좌우 포탈 통과`를 켜면 A/B 사이를 이동한다. 실제 영역 모드에서는 `표시할 화면`의 0=A, 1=B로 상대 영역을 본다. 화면 선택만 바꿀 때는 구슬을 초기화하지 않는다.
- 화면 크기나 영역 모드가 바뀌면 영역을 다시 계산하고 배치를 초기화한다. 구슬 크기 변경은 표시·충돌·잡기 범위를 함께 바꾼다.

## 조절하는 일곱 값

| Config 필드 | 의미와 조절 방향 |
|---|---|
| `orbRadiusScreenFraction` | 구슬 반지름 비율. 크게 하면 구슬과 잡을 수 있는 원의 범위가 커진다. |
| `orbRestitution` | 구슬끼리 또는 벽에 충돌할 때의 반발력. 크게 하면 더 많이 튄다. |
| `orbContactFriction` | 콜라이더가 접촉하는 동안의 마찰. 접촉면을 따라 미끄러지는 느낌에 관여한다. |
| `orbFloorDeceleration` | 자유롭게 미끄러지는 구슬의 감속량. 크게 하면 더 빨리 멈춘다. |
| `orbStopSpeed` | 이 속도 이하에서 완전히 정지시킬 기준. 크게 하면 마지막 미세 움직임이 일찍 끝난다. |
| `orbMaxReleaseSpeed` | 손을 놓을 때 적용할 속도의 상한. 모든 드래그의 속도를 배율로 늘리는 값은 아니다. |
| `orbReleaseSampleWindow` | 손을 놓기 직전 속도 계산에 사용하는 시간 구간(초). 짧으면 마지막 움직임에 더 민감하다. |

속도와 감속은 **조합대 너비**를 기준으로 정규화한다. 예를 들어 최대 속도 2는 초당 조합대 너비 두 배다. 수평·수직 속도 모두 같은 너비 단위를 사용한다. 현재 게임은 `Rigidbody2D.linearDamping` 대신 `orbFloorDeceleration`으로 감속하므로, Rigidbody Inspector의 Damping을 직접 바꾸지 말고 이 일곱 값으로 조절한다.

값이나 구슬 크기를 바꾸면 기존 solver가 진행 중인 드래그와 관성을 정리하고 새 값을 적용한다. 멈춘 구슬을 다시 던져 비교한다. 먼저 반발력·감속·최대 속도를 조절하고, 그다음 정지 기준·샘플 구간을 조절하면 변화를 구분하기 쉽다.

## 저장·다시 읽기·배치 초기화

- **저장**: 현재 조절 중인 일곱 값을 `Assets/_Project/HapioMVP/Config/ScreenLayoutConfig.asset`에 기록한다. 다른 전투·자원·투척 설정은 저장 대상이 아니다.
- **다시 읽기**: 공용 Config에 마지막으로 저장한 값으로 현재 조절값을 되돌린다. 저장하지 않은 시험값은 버려진다.
- **배치 초기화**: 구슬 위치와 움직임을 테스트 시작 상태로 돌려 같은 상황을 다시 시험한다. 조절값 저장과는 별개의 동작이다.

일반적인 Play 중 씬 오브젝트 변경은 Play 종료 시 되돌아간다. 공용 Config에 명시적으로 저장한 값은 남으며, 실제 게임이 다음 세션에서 Config를 읽을 때 사용한다. 이미 진행 중인 네트워크 방의 설정을 덮어쓰는 기능은 아니다.

## 포탈과 확인 범위

두 조합대는 한 컴퓨터 안에서 상대 화면을 흉내 낸 **로컬 데모**다. 구슬이 좌우 경계를 넘으면 같은 구슬을 반대쪽 조합대의 대응 출구로 넘긴다. 잡고 있는 동안에는 전달하지 않고, 손을 놓은 뒤 움직여 경계를 넘을 때 전달한다.

진입 높이는 구슬 중심이 안전하게 움직일 수 있는 세로 구간의 비율로 매핑한다. 남은 속도와 방향은 조합대 너비 기준으로 전달한다. 서로 다른 너비를 사용하면 정규화한 속도가 보존되며, 월드 좌표의 초당 이동 거리가 같다는 뜻은 아니다. 충돌과 바닥 감속은 실제 게임과 같은 `LocalOrbPhysicsBoard`가 처리한다.

상·하단 벽 반발, 음·양 구슬 충돌, 느린/빠른 손떼기, 이동 후 잠깐 멈췄다가 놓기, 좌우 전달 후 다시 잡기, 모서리와 겹침을 확인한다. 자연 접촉만으로 음·양 구슬을 합치지는 않는다.

기존 게임 씬과 게임 진행 코드는 유지한다. 다만 저장하면 공용 설정값은 다음 게임에 반영된다. 실제 게임의 구슬 크기에는 기존 HUD·그리드 크기 상한과 여백 규칙이 추가로 적용되므로, 테스트 씬에서 본 크기와 최종 화면을 함께 확인해야 한다.

## 이번 작업의 검증 상태

- 설치된 Unity의 실제 어셈블리를 참조한 런타임·Editor·테스트 소스 컴파일: PASS. 가짜 API 스텁 검사가 아니다.
- 별도 사본의 Unity batch 실행: BLOCKED. 라이선스 초기화/`com.unity.editor.headless` 연결 문제로 초기화를 완료하지 못했다. 이 검사 프로세스만 정상 종료 신호로 정리했다.
- PlayMode 테스트 및 마우스/Unity Remote 실제 조작: NOT_RUN. 테스트 소스 컴파일을 테스트 실행 PASS로 보지 않는다.
- 씬 생성은 `C6 > Physics Sandbox > Open Tuning Scene`에서 반복 가능하다. 설치 시 에디터가 새 스크립트를 컴파일하면 새 에셋만 생성하도록 준비 요청을 전달한다. 현재 열려 있는 씬을 자동으로 바꾸거나 Play하지 않는다.
- 네트워크 승인·실제 두 핸드폰 캐치 감도·조합/3D 공격·기기 앱 성능 검증은 범위 밖이다.
