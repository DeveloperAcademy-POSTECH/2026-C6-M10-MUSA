# 야광귀 콤보 예고·진행 에셋 (#668)

## 현재 표시

- `LabGourdAlert.ShowWord`의 하나/둘/셋/넷(느낌표 포함)은 제공된 완성 PNG로 표시한다. 논리 Label은 유지하되 Text는 숨겨 글씨가 겹치지 않는다. 일반 문장·폭탄·하트·눈·해제 말풍선은 기존 경로로 전환한다.
- `LabGourdComboHud`는 야광귀 셈법일 때 Figma 패널을 표시한다. 판정은 기존 Host의4칸 `comboColors`와 `comboProgress`를 그대로 읽는다. 5종 구슬 PNG 중 실제 순서에 해당하는 그림을 사용하고, 완료된 칸에만 체크를 겹친다.
- 최신 패널은 Figma `4841:11338`의207×51 비율을 사용한다. 실제 전투에서는 `Paint Progress/Frame`의 위치를 읽어 그 중앙에 겹치고 폭은 게이지 프레임의98%로 정한다. 구슬26.27368×26.82105와 시간 바180.72632×3.83158의 원본 비율을 유지한다.
- 패널 위의 수와 외부 ? 칸은 새 시안에 없으므로 새 패널에서 숨긴다. 야광귀 셈법이 꺼지면 기존 패널과 표시 경로를 유지한다. 남은 시간 계산·입력·순서·성공/실패·일시정지·보상 판정은 바꾸지 않는다.

## 에셋

`Resources/Yaguang/Combo`의 Single Sprite PNG12개를 사용한다. 컬러·질감·글씨를 새로 그리거나 tint하지 않는다. 패널/구슬/체크/막대는 Figma 원본2배, 카운트 말풍선은 첨부 원본125×125다. 무압축·mipmap OFF·최대2048로 임포트해414×102 패널과600×14 막대가512px로 축소되지 않게 한다.

- Group675 → CountThree, Group676 → CountTwo, Group677 → CountOne, Group678 → CountFour. 네 파일은 첨부 원본과 해시가 동일하다.
- Earth/Wood/Fire/Water/Metal은 각각 갈색/초록/빨강/파랑/노랑 원본이다. 체크는 독립 PNG이며 동적으로 표시한다. `LabYaguangComboArt`가 원소→파일을 매핑한다.
- 패널 배경은 원본 프레임의 fill·stroke를 자식 없이 추출했다. 임시 clone은 즉시 삭제해 Figma 원본을 보존했다. 시간 바는 원본 dark-ink PNG를 폭으로 줄이고, 트랙은 같은 PNG를15% alpha로 표시한다.
- 파일 키/노드/기준 크기는 `Source.json`에 기록했다. 새 에셋은 `LabBattleRenderWarmup`의 실제 UI 렌더링 준비에 포함한다.

## 검증과 한계

실제 실행 결과는 `VALIDATION.md`의 #668 기록을 따른다. Unity 컴포넌트 미리보기에서 빈 상태/2개 완료/카운트4종을 확인했다. 실기기·네트워크 다인 전투·전체 게임 화면에서의 배치는 별도 확인 대상이다.

## 게이지 위 교체 표시

- 실제 게이지가 있으면 화면상의 고정 좌표 대신 게이지의 world corners를 콤보 레이어 로컬 좌표로 변환해 배치한다. 게이지가 없는 미리보기는349×765의71/107/207×51 기준을 사용한다.
- 콤보 판은 앞 레이어에 놓고0.22초 SmoothStep으로 페이드 인한다. 등장 첫 프레임부터 뒤의 `Paint Progress` 전체(프레임·채움·퍼센트)를 CanvasGroup alpha0으로 숨겨 비치지 않게 한다.
- 판/같은 위치의 결과 표시가 끝나거나 Pause/비활성화/파괴 때 게이지의 이전 alpha를 복원한다. 아래쪽의 짧은 비최종 숫자 피드백만 남은 경우에는 게이지를 계속 숨기지 않는다. 추가한 CanvasGroup은 소유 수명에 맞춰 정리한다.
- 게이지의 실제 값/판정은 계속 계산되며 표시 alpha만 바꾼다. 콤보 숫자와 결과도 판과 같은 기준점을 사용한다.
