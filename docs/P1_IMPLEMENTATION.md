# P0/P1 구현 · 기준 몬스터와 평면 구슬 물리

2026-09-14. 기준 커밋 `741a020`, 새 씬 빌드 식별자21. 이번 변경은 사용자가 승인한 새 계획의 **P0 공통 준비와 P1 2D 물리**다. 실제 결과는 [P1 검증](P1_VALIDATION.md)에 따로 기록한다.

## 이번에 달라진 동작

새 `PhysicsBattle.unity`에서 구슬을 밀듯이 드래그하고 손을 놓으면 최근 움직임에 따라 미끄러진다. 구슬과 벽에 부딪히면 밀림·반발이 생기고 바닥 저항으로 서서히 정지한다. 화면 아래로 떨어지는 중력은 없고, 글자가 돌아가지 않도록 회전은 고정한다.

잡는 즉시 관성을 멈추고 기존 확대·빛 효과를 표시한다. 잡고 있는 구슬의 고체 충돌은 잠시 끄므로 다른 구슬 위에 겹쳐 놓을 수 있다. **직접 드래그의 정상 손떼기에서만 조합 요청을 보낸다.** 자연스러운 Yin/Yang 충돌은 밀림만 만들며, 벽에 닿아도 자동 전달·공격하지 않는다.

정상 하단 놓기 한 번은 조합, 전달 또는 관성 이동 중 하나다. 조합·전달의 거절 응답이 즉시 돌아오더라도 같은 입력을 관성 발사로 다시 사용하지 않는다. 취소 입력은 잡기 시작 위치로 정리하고 속도를 남기지 않는다.

## Unity에서 책임을 나눈 방법

| 파일 / 자산 | 맡은 일 |
|---|---|
| `Orbs/LocalOrbPhysicsBoard.cs` | Rigidbody2D·CircleCollider2D·벽·마찰감·최근 위치/시간 기록. 네트워크 행동을 호출하지 않음 |
| `Battle/T09BattleController.cs` | 기존 직접 입력과 Host 승인 흐름에 물리를 선택적으로 연결 |
| `Attack/BenchmarkMonster.cs` | 한 Config로 몬스터 위치·피격상자를 적용. 체력은 보관하지 않음 |
| `Prefabs/BenchmarkMonster.prefab` | 표적 식별 루트, Collider 없는 Visual, 정적 Hitbox를 분리 |
| `Scenes/PhysicsBattle.unity` | 기존 빌드20에서 파생한 새 실행 씬. 2인 흐름과 새 물리를 연결 |
| `Editor/PhysicsBattleBuild.cs` | 씬·Prefab을 반복 준비하고 별도 출력 경로에 빌드하는 메뉴 |

물리 구슬은 평소 Dynamic, 잡기·승인 대기·정지된 전투에서는 Kinematic과 Trigger 상태로 전환한다. 손을 놓으면 Dynamic으로 돌아오며 요청 대기 중인 재료 둘은 움직이지 않는다. 명확한 거절은 겹침을 해소한 뒤 복귀시키고, 성공은 재료 둘을 제거하고 새 ID의 Combined를 정지 배치한다.

소유한 기기에서 하단 물리를 계산하고, Host는 기존대로 논리 소유권·소비·조합·피해·자원을 확정한다. 일반 상태 수신은 움직이는 구슬을 생성 위치로 되돌리지 않는다. 새 생성·수신·라운드 변경·화면 크기 변경은 명시적인 위치 정리로 취급해 과거 속도를 지운다. 수신 구슬은 반대쪽 경계의 빈 위치에 정지해서 도착한다.

## 직접 조절하는 수치

원본은 기존 `Assets/_Project/HapioMVP/Config/ScreenLayoutConfig.asset` 하나다. 새 항목은 Inspector의 **P1 · Flat orb board**에서 찾는다. 아래 값은 사용자 확정 수치가 아니라 조작감을 맞출 `DEMO_TUNING_VALUE`다.

| Inspector 필드 | 초기값 | 뜻 |
|---|---:|---|
| Orb Restitution | 0.65 | 벽·구슬 접촉의 반발 정도 |
| Orb Contact Friction | 0.15 | 접촉면의 마찰 |
| Orb Floor Deceleration | 0.6 | 초당 줄이는 속도. 작업판 너비/초² 단위 |
| Orb Stop Speed | 0.015 | 이 속도 이하를 정지로 처리. 작업판 너비/초 |
| Orb Max Release Speed | 2 | 정상 놓기의 최대 초기 속도. 작업판 너비/초 |
| Orb Release Sample Window | 0.12초 | 놓기 직전 방향·속도를 계산하는 구간 |

감속을 높이면 더 짧은 거리를 움직이고 빨리 멈춘다. 반발을 높이면 충돌 후 튀는 움직임이 커진다. 평면 위 이동에는 접촉이 없는 구간이 있으므로 접촉 마찰만으로 정지를 구현하지 않고 별도 바닥 감속을 적용한다. [Unity 물리 머티리얼 2D](https://docs.unity3d.com/kr/6000.0/Manual/2d-physics/physics-material-2d-reference.html).

가로·세로를 각각 0~1로 만들어 물리 원을 찌그러뜨리지 않는다. 실제 카메라의 같은 월드 단위로 두 축을 계산하고, 위 수치의 기준 너비만 기기 작업판에 맞춰 변환한다. 라벨·버튼·하단 여백을 제외한 경계에서 구슬이 움직인다.

## 보존과 후속 범위

기존 씬은 새 물리를 켜지 않으며 파일과 `.meta`를 보존했다. 공통 Controller의 선택 항목 `Orb Physics Enabled`는 새 씬에서만 켠다. 새 씬의 시작0개·스태미나100·생성20·시간회복20/3초·명중+5·HP100·180초·좌우 전달은 유지한다.

P1 공격은 아직 **기존 상단 경계 통과·고정 방향 발사**다. 손을 놓는 순간 방향·세기를 계산하는 3D 중력 투척은 P2, 최대5인 로비·원형 이웃·게임 동기화는 P3의 후속 구현이다. 기준 몬스터 규격은 [별도 문서](MONSTER_TARGET_SPEC.md)에 있다.

새 물리·표적 필드는 같은 빌드/같은 Config 기준으로 적용한다. Inspector에서 한 기기의 실행 사본을 바꾼 내용까지 자동으로 원격 전파하지 않으며, P3에서 새 설정 메시지·지문을 확장한다. 수치를 바꾼 비교는 Play를 종료하고 Config를 수정한 뒤 같은 조건으로 다시 실행하는 것을 기준으로 한다.
