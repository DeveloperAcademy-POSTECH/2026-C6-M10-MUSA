# T08 · 음양 1단계 조합 결정

2026-09-13 최신 사용자 요청으로 T08만 진행한다. 선행 T07 소스301개와 시험300개·원시로그20개·Mac/iOS 산출물을 재확인하고 당시 현재문서6개를 docs/history/2026-09-13-t07에 보존했다.

## 규칙과 위치

일반 시작은 구슬0개·Stamina100/100이다. 매 Generate는 비용20의 Raw1개이며 시간 회복20/3초와 실제 명중의 공격자 +5는 그대로다. 조합은 추가 비용이나 보너스를 발생시키지 않는다. 정상 시간 회복은 계속될 수 있으므로 거부 전후 수치가 반드시 같아야 한다고 해석하지 않는다.

같은 소유자의 Idle Raw Yin과 Raw Yang 두 개만 가능하다. Host가 session/round/request, 실제 송신자·nonce, 서로 다른 ID, 소유권·종류·음양·예약·순번을 검증한다. 두 기존 ID를 원자적으로 Consumed로 바꾸고 새 ID의 Combined/None/Idle 하나를 만든다. CanAttack은 true, CanCombine은 false다. 전달·발사 예약과 같은 HostOrbRegistry를 공유한다. 보관 수는2→1로 줄며 자원 계정은 변경하지 않는다.

중앙 위치 정책은 **Drop 시 두 표시 중심의 중간점**이다. 요청 좌표는 하단 전체 viewport가 아닌, footer와 Attack Zone을 제외한 `OrbGridScreenRect` 안의 정규화 좌표[0,1]다. source는 잡은 구슬의 실제 표시 중심(손가락과의 간격 반영), target은 가장 가까운 다른 구슬의 표시 중심이다. Host는 finite·범위를 검증하고 로컬2D물리를 복제하지 않는다.

## 입력과 복구

기존 입력 중재를 유지한다. 원래 Pointer로 Attack Zone/Swipe를 먼저 검사하고 표시를 Clamp한다. Combined Zone 최초 진입이 같은 갱신의 Swipe보다 우선하며, 먼저 요청한 행동을 다른 행동으로 바꾸지 않는다. Raw는 위로 움직여도 발사되거나 삭제되지 않는다.

아무 요청이 없었던 유효한 Pointer Up에서 가장 가까운 모든 사용 가능 구슬을 먼저 고른다. 같은 음양을 노렸는데 조금 먼 반대 음양으로 바뀌는 동작을 막는다. 가까운 두 중심이 전체 너비0.08 안이면 Host에 조합 요청을 보내며, 같은 음양·Raw+Combined·Combined+Combined는 실패 피드백과 원본 보존으로 처리한다. 단순 접촉·Move는 조합하지 않는다. 화면 밖 Pointer Up은 Clamp된 표시가 가까워도 조합하지 않는다.

수평 Swipe 임계값0.18·우세1.25는 변경하지 않았다. 멀리 수평 이동하면 후속 전달 행동으로 분류되어 현재는 거부된다. 인접 구슬은 조합 반경 안쪽에서 짧게 놓거나 세로로 Drop할 수 있다. 실제 전달은 T11이다.

두 재료는 요청 전부터 함께 잠근다. 응답은 실제 Host·nonce·session/round·두ID·순번·좌표가 원 요청과 일치해야 적용한다. 불명확한 결과나 다른 행동의 예약이 남아 있으면 잠금을 유지한다. 3초 뒤 동일 요청의 결과를 조회하며, 8초 안에 확정할 수 없으면 세션을 오류로 종료한다. 재전송으로 대체 구슬을 만들지 않는다. 컨트롤러만 중단돼 조회를 수행할 수 없을 때도 미확정 요청이 있으면 세션을 종료한다.

성공 영수증의 최초 Combined와 조회 시 현재 상태를 구분한다. 오래된 Idle snapshot이 이미 소비·발사된 구슬을 다시 만들지 않도록 ID를 기억한다. 성공 결과 인벤토리의 확인도 조회·종료 제한 안에서 수행한다. 이전 라운드의 요청과 결과를 새 라운드로 넘기지 않는다.

## 씬과 개발 도구

새 `CombinationSmoke.unity`는 저장된 `ResourceSmoke.unity`에서 별도로 파생한다. 기존 두 카메라·단일 Config·발사 기준·표적 Collider를 유지하고 별도 T08 HUD/입력·조합 서비스를 연결한다. 기존 씬·meta를 덮어쓰지 않는다. Unity6000.5.7f1과 패키지도 유지한다.

T08 `MIXED FIXTURE`는 명시적 새 Debug 라운드에서 개인별 Yin3/Yang2의 Raw5개를 공급한다. 직전 T07의 같은 음양5개 Fixture API는 유지한다. T08에는 무료 Combined 버튼이 없고, 공격 시험은 실제 조합 결과를 사용한다. 일반 HOST/JOIN/RESET EMPTY는 무료 구슬을 공급하지 않는다.

일반 Seed 자동 시험과 Debug Fixture 결과를 구분한다. 일반 Seed가 원하는 음양 개수를 보장하지 않으므로, 자동 실행은 필요한 경우 정상 시간 회복과 유료 생성을 추가하며 제한 시간·보관 상한을 넘으면 실패로 기록한다.

## 범위

T08은 AT-05/06 조합과 AT-17 Raw 공격 거부를 연결한다. 실제 Drop 성공·거부의 사람·실기기 Gate는 통합 지시서에 따라 T09에서 확인한다. Mac Pointer 자동화나 iOS 프로젝트 생성만으로 실제 iPhone Touch·Safe Area·FPS 또는 G4 전체를 PASS로 선언하지 않는다. Team HP·180초·정식 승패·Ready/Host Start는 이번 범위 밖이다.
