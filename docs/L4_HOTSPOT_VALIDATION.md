# L4 핫스팟 실환경 확인

2026-09-15 · **핫스팟 범위 PASS / L4 전체는 미완료** · 기존 앱26·게임 계약24 재사용

사용자가 현재 핫스팟만 가능하다고 확인했다. 재빌드·재설치·전체 자동 검사 반복 없이 한 번의 묶음 절차로 확인했다. 게임 소스·패키지·Config·씬을 변경하지 않았다.

| 항목 | 결과·근거 |
|---|---|
| 핫스팟 새 방 입장·게임 시작 | PASS — 양쪽 같은 방/세션에서 Playing·게임 초기 상태 확인 |
| 왕복 전달·직접 조합·투척 후 HP80 | PASS — 안내한 절차에 대한 사용자 ‘잘 돼’ 응답. 연결 로그에는 해당 게임 수치가 없음 |
| 180초 종료·결과 고정 | PASS — 사용자 확인. 로그의 Playing→방 Closed 간격은 약187.07초로 부합하지만 결과 화면 자체를 기록한 것은 아님 |
| 종료 후 새 방 재입장 | PASS — 새 방·새 세션, 양쪽 Connected·참가자2명·초기 상태 확인. 방/세션/Config/명단 일치 |
| USB 케이블 분리 | 묶음 절차에 포함해 정상 응답을 받음. 앱에서 물리적 분리를 별도 측정하지 않았음 |
| 일반 공유기 Wi-Fi | NOT_RUN — 환경 미확보 |
| 인터넷 없는 별도 LAN | NOT_RUN — 환경 미확보 |

Client는 IPv6를 사용했다. 기기 기록의 runtimeError와 error는 비어 있고 기록 잘림도 없다. iPad의 CONNECTION_LOST1건은 게임 시작 전 기존 방을 Host가 닫은 약0.20초 뒤에 발생했으며, Host 종료 사유와 일치한다. 플레이 후 퇴장은 양쪽 USER_CANCELLED로 기록됐다. 이 정상 정리 기록을 숨기거나 플레이 중 단절로 해석하지 않는다.

이번 확인은 실제 사용자 조작과 연결 기록의 결합이다. 전체 게임 상태 스냅샷·피격 로그 대조나 자동 Touch 검사로 표현하지 않는다. 한 번의 성공을 모든 공유기·통신사·약한 Wi-Fi에서의 성공률로 일반화하지 않는다.

[실행 요약](validation/L4_20260915.json). 원시 기기 기록은 로컬 `c6-l4-checks/hotspot-final-01`에 보존하며 공개하지 않는다. 다음 재개 항목은 **L4의 일반 Wi-Fi와 인터넷 없는 LAN 확인**이다. 두 환경을 확보하기 전에는 L4 전체 PASS로 기록하지 않는다.
