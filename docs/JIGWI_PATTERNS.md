# 지귀 수동 패턴 — #272

기준: 기존 `Assets/Lab/Scenes/Lab.unity` 단일 Scene, Unity6000.6.5f1. #262의 3스테이지 구조는 포함하지 않는다. 이번 패턴은 자동 방해공작 추첨에 추가하지 않으며 Editor/Development 빌드의 Host 또는 솔로에서 수동 발동한다. 실행 결과는 [VALIDATION](VALIDATION.md)의 #272 기록을 따른다.

## 직접 시험하기

1. Lab Scene을 Play한다. DEV에서 수치 변경이 필요하면 **Jigwi** 카테고리를 조정한 뒤 SOLO 또는 공유 방을 시작한다. 공유 방은 Host 설정184개를 전원 확인하는 기존 경로를 사용한다.
2. 전투 중 Host 화면의 **JIGWI DEV**를 누른다. 대상 P번호를 선택하고 **START FIRE CHALLENGE** 또는 **START RAW GENERATION BURN**을 누른다. 성공하면 시험 패널이 닫혀 즉시 조작할 수 있다. Client에게는 수동 발동 버튼을 표시하지 않는다.
3. 일시정지 중에는 발동할 수 없다. 전투를 재개한 뒤 발동한다. 기존 지귀 효과가 활성인 같은 대상에게 중복 발동하지 않는다.
4. 별도 모델/텍스처를 설치할 필요 없이 불길·불타는 구슬·재/연기는 Unity 기본 도형과 기존 연기로 표시한다. Canvas의 저장된 `LabJigwiHud`와 자식 UI를 Inspector에서 조정할 수 있다.

## 화재 도전과 과열

- 대상 화면에 실제3D 불길 표적N개를 배치하고 수 Combined를 **N+2개** 한 번 지급한다. 스태미나·일반 생성 횟수를 쓰지 않으며 기존 구슬을 지우지 않는다. 보급은 일반 보관 한도와 분리한다. DEV 연속 발동의 무한 누적을 막는 플레이어별 보급64개 안전 한도를 넘으면 새 도전 전체를 거절하며 기존 상태를 보존한다.
- 보급은 최소 도전 종료 시각까지 사용할 수 있고, 투척 후에는 기존 비행 소비 규칙을 따른다. 남은 보급을 다음 도전 시작 시 강제로 지우지 않는다.
- 수 Combined를 실제로 위쪽으로 던져 불길에 맞춘다. 손을 놓는 즉시 소화되는 드래그 표적이 아니다. 표적 하나당 수 Combined 한 번이며 전부 끄면 성공한다. 다른 속성은 소화하지 못하고 해당 투척은 소비된다.
- 충돌은 박/불길/바닥 중 실제로 먼저 접촉한 표면을 선택한다. 불길 명중은 박 HP·도색·명중 보상을 만들지 않는다. 박을 실제로 먼저 맞힌 투척은 기존 박 판정을 유지한다. 오래된 불길/이전 라운드 명중은 새 불길을 끌 수 없다.
- 제한시간까지 모든 불길을 끄지 못했을 때만 과열된다. 도전 중 조작은 정상이며 빗나가도 제한시간 안에 재시도할 수 있다. 화재·과열 중인 사람에게 기존 자동 방해공작이 추가로 매혹을 걸어 물 투척을 막지 않도록 대상에서 제외한다.

| 과열 중 행위 | 결과 |
| --- | --- |
| 생성 | 정상 비용·생성 횟수 적용 후 구슬이 불타 사라짐. 북은 유지. 결과 구슬을 저장하지 않으므로 보관 한도로 거절하지 않음. |
| 드래그 | 들고 움직일 수 있으며 손을 놓을 때 해당 구슬 하나 소각. |
| 유효한 직접 음양 조합 | 두 원재료 모두 소각하고 결과 Combined/조합 보상을 만들지 않음. |
| 수동 전달·투척 | 구슬을 소각하고 새 전달·투사체를 만들지 않음. |
| 아이템 사용 요청 | 과열로 늦게 도착한 사용 요청도 소각하며 회복·새 구슬·사용 보상을 만들지 않음. |

단순 보유·터치 취소·자동 물리 이동·자연 접촉·수신·이미 날아간 투사체는 조작 소각과 분리한다. 접촉 조합이 켜져 있을 때 자연 음양 충돌은 과열 중에도 기존처럼 정상 Combined를 만든다. 요청에 자연 접촉 여부를 포함해 늦게 도착해도 수동 조합 소각과 구분한다. 북은 소각하지 않는다. 입력을 잠그거나 과열 때문에 Time.timeScale을0으로 바꾸지 않으므로 전투 시간과 물리는 계속 진행한다. 공동 일시정지는 기존대로 전투 시계를 멈춘다.

## 생성 화상

활성 기간에 새로 생성되는 Yin/Yang만 지귀 반지름·만료 시각을 부여한다. 기존 구슬/북/아이템/Combined에는 새 화상을 부여하지 않는다. 전달해도 ID·반지름 배율·절대 만료 시각이 유지된다. 패턴 기간이 끝나면 새 구슬은 정상 생성되며 이미 태어난 화상 Raw는 자기 만료 시각까지 같은 성질을 유지한다.

화상 Raw를 정상 조합하면 새 Combined는 지귀 화상이 없는 정상 수명·크기로 시작한다. 기존 폭탄의 `small/burnedAt`는 별도이며 원래 상속·공격 면적 규칙을 유지한다. 이 패턴 자체가 과열을 만들지는 않는다.

## 조절값과 소스

원본은 `Assets/Lab/Resources/LabConfig.asset`이다. 기존178개 뒤에 지귀6개(178~183)를 유지하고, 야광귀 섬광7개(184~190)를 통합하고 야광귀 셈법191을 더해 전체192개이며, 통신은5658·연결 토큰`C6PhysicsLab/19`이다. 이전 Lab 빌드와 혼용하지 않는다. 실행 중 DEV는 복사본을 조정하고 일반 방에서는 Host가 공유·확인 후 적용한다.

| 인덱스(0부터) / DEV 이름 | 기본값 | 범위 |
| --- | --- | --- |
| 178 / Jigwi Fire Target Count | 1 | 정수1~5 |
| 179 / Jigwi Fire Seconds | 15초 | 1~120초 |
| 180 / Jigwi Overheat Seconds | 4초 | 0.1~60초 |

- `LabModel.Jigwi`·`LabContracts`: 패턴 인스턴스, 지급, 실패, 구슬 소비·수명과 상태. Host ID0도 실제 참가자다.
- `LabNetwork.Jigwi`·`LabNetwork.Actions`: DEV 권한·소유권 검증, 실제 명중 분기, 빠른 로컬 예측/승인/거절 복원. 소각은 `consumedWithoutOutput`로 결과 없이 끝나는 성공 요청이며 종속 예측도 정리한다.
- `LabBoardReplication`: 작은 보드 Header의 패턴 상태와 구슬 메타를 공유한다. 큰 페인트 체크포인트를 기다리지 않는다.
- `LabProjectile`·`LabJigwiFireSurface`: 기존 투척 입력·중력·속도·궤적을 유지하면서 별도 불길 표면을 실제 판정에 포함한다.
- `LabOrbBoard`·`LabJigwiBurnEffect`: 손떼기 소각과 승인 거절 시 구슬 복원, 별도 생성 화상 반지름, 도형 불·축소·연기.
- `LabJigwiHud`: 수동 시험 버튼·대상 선택·수신자 타이머/화면 열기 표시. `LabJigwiSceneUpgrade`는 기존 Lab에 이 UI만 명시적으로 추가하는 도구다.

Retry·로비·새 방에서는 이전 패턴/불길/소각 예측을 정리한다. 기능 추가를 이유로 Lab Scene을 재생성하거나 Scene/프로젝트 이름을 바꾸지 않는다.
