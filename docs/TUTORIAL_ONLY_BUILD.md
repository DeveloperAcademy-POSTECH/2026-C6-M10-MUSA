# 튜토리얼 반복 전용 앱 (#810)

## 목적과 흐름

현재 main의 타이틀과 기존 튜토리얼을 재사용하는 별도 앱이다. 앱이 켜지면 기존 타이틀을 표시하고, **게임 시작 → 기존 튜토리얼 → 타이틀**을 횟수 제한 없이 반복한다. 자동 튜토리얼 진입이나 별도 완료 화면을 추가하지 않는다.

- 학습 단계·대사·조작·행동 성공 조건·가상 이웃·튜토리얼 아트·소리·북/구슬/폭탄 규칙은 기존과 같다.
- 전용 앱의 게임 시작은 오프닝 이야기·방 목록을 거치지 않고 튜토리얼을 연다.
- 완료·건너뛰기 확인·일시정지 메뉴의 나가기는 타이틀로 돌아간다. 일시정지 메뉴의 재시작은 기존처럼 연습을 처음부터 다시 연다.
- 타이틀에서 다시 게임 시작을 누르면 새 상태로 튜토리얼을 실행한다. 이전 구슬·대화 기록·진행 단계·조작 잠금이 새 판에 남지 않아야 한다.
- 준비 실패나 연결 정리/Scene 전환 중 클릭으로 방 목록·일반 게임이 열리지 않게 한다. 전환이 끝나야 다음 시작을 받을 수 있다. 종료 중인 전투 HUD의 자동 방 검색도 전용 앱에서만 취소한다.

일반 게임의 최초 튜토리얼/방 목록 진행과 야광귀 단판 시연은 기존 정책을 유지한다. 기존 Home·공통 Battle과 저장 자료를 쓰고 Scene을 복제하지 않는다. 튜토리얼 내부의 로컬 Host·물리·판정 구조도 변경하지 않는다.

## 빌드 구분

전용 앱은 `HAPIO_TUTORIAL_ONLY`로 구분한다. 튜토리얼 진입을 막는 Staff/Yaguang 시연의 `IsDemo`에는 합치지 않는다. 전용 define은 저장된 Player Settings에 상시 추가하지 않고 빌드에만 전달한다.

- 앱 표시명: `합이오_튜토리얼`
- 기존 일반/시연 앱과 구분되는 전용 앱 식별자 및 출력 폴더 사용
- Release 빌드의 기존 숨김 DEV 차단 유지
- 기존 합이오 로고와 사용자 제공 원본 앱 아이콘 재사용
- 현재 공통 Scene 목록과 필수 자료를 유지하고, 실행 경로만 튜토리얼로 제한

전용 빌드 도구는 저장된 제품명·식별자·버전/빌드 번호·아이콘·스플래시·define·Scene 목록·플랫폼과 ProjectSettings 파일을 정상/실패 모두 원복해야 한다. 일반/시연 빌드의 검증·기본값을 튜토리얼 전용 값으로 바꾸지 않는다.

## iOS 빌드 방법

1. Play를 종료하고 저장할 변경을 정리한다. 기존 Scene을 수정하거나 복제할 필요는 없다.
2. Unity의 **Hapio → Tutorial Only Build → Release → Export iOS Xcode Project**를 선택한다.
3. 출력은 `Builds/HapioTutorialOnly/<생성시각-고유번호-release>/iOS/Unity-iPhone.xcodeproj`이다. **Open Last Output**으로 마지막 출력 폴더를 찾을 수 있다.
4. 다른 컴퓨터의 Xcode에서는 본인 Team과 연결 기기를 선택해 서명·설치한다. 인증서나 프로비저닝 파일은 저장소에 포함하지 않는다.

표시명은 `합이오_튜토리얼`, 실행 파일은 `HapioTutorial`, 앱 식별자는 일반 앱 식별자 뒤에 `.tutorial`을 붙인다. 출력의 `build-manifest.json`에서 전용 variant·Release 여부·필수 아이콘 원본의 해시·출력 검증 결과를 확인할 수 있다. 같은 폴더에 덮어쓰지 않고 매번 새 출력을 만든다.

저장된 Player Settings에 전용 define을 직접 넣지 않는다. 일반 빌드 도구와 시연 빌드 도구는 저장된 variant define이 있으면 중단해 잘못된 앱 구성이 섞이는 것을 막는다.

## 원본 아이콘

`BuildSupport/Branding/AppIcon.icon`은 사용자가 제공한 원본 그대로다. Unity Assets 밖에 보관해 Unity Sprite로 다시 그리거나 변환하지 않는다. iOS 출력에 복사하고 Xcode의 native Icon Composer 아이콘으로 연결한다. 앱 본체만 해당 아이콘을 사용하며 UnityFramework 아이콘은 건드리지 않는다.

## 확인 범위

실제 타이틀, 게임 시작 후 첫 튜토리얼, 완료 후 타이틀 복귀, 다시 게임 시작 후 초기 상태를 촬영해 확인한다. 건너뛰기 취소/확인·일시정지 재시작/나가기·빠른 연타·준비 실패와 일반 게임/시연 비회귀도 검사한다.
