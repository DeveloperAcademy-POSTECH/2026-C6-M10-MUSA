## 실패와 수정 보존

1. 최초 EditMode 17실패: 확장 snapshot 용량1개, NaN 입력의 거부 결과 재조회1개, 새 설정 필드가 빠진 기존 시험 데이터15개. 원인 수정 후1,071개 모두 통과했다.
2. 최초 Mac 빌드: 진단용 창 이동 API의 `ref`/`in` 표기 차이로 컴파일 실패. Unity·언어 버전 변경 없이 설치본 API에 맞췄다.
3. 최초 두 앱: Client 표시 공의 Collider가 비활성화된 뒤 프레임 말 삭제를 기다리는 상태를 진단 도구가 활성 물리로 오판했다. Client가 종료해 Host도 명중 대기 실패했다. 활성 Collider만 검증하도록 고치고 재실행했다. 물리 권한 처리는 바꾸지 않았다.
4. 두 번째 두 앱은 상태111개 일치로 통과했으나 캡처에서 취소 후 THROW READY 문구가 남는 것을 발견했다. 취소·하단 복귀 안내를 고치고 관련6개·최종113개 상태 비교로 다시 확인했다.

초기 실패·중간 성공·최종 성공을 [검사 집계](P2_TEST_REPORT.md)와 근거 폴더에 분리 보존했다. 최종 Unity 출력은 경고13·오류0이며 폐기 예정 API와 관련된 경고를 포함한다. 패키지·렌더러 업그레이드는 하지 않았다. 서명 검증의 첫 sandbox 신뢰 저장소 접근 오류는 같은 앱을 시스템 신뢰 저장소로 검증해 종료0을 확인했고, 앱 파일 변경은 없었다.
