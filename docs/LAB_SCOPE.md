# C6 Physics Lab 범위와 검증 기준

작성 기준: Unity **6000.6.5f1** 신규 프로젝트의 코드·설정 구조. **이 문서는 구현 범위와 확인할 동작을 정리하며 실행 결과를 주장하지 않는다.** 구 프로젝트의 코드·Scene·그래픽을 통째로 이식한 버전이 아니다.

## 포함하는 동작

| 범위 | 현재 실험실의 규칙과 책임 |
| --- | --- |
| 연결 | 같은 로컬 네트워크에서 Host가 일반 로비의 **ROOM PLAYERS**로 **2~5명** 목표 인원(기본 3명)을 정하고, 목표 인원이 모여 같은 설정을 확인한 뒤 시작한다. DEV 인원 선택은 같은 목표값을 사용한다. 인원은 방 생성 전에만 변경한다. 기본 포트는 `7777`이며 방 목록에서 선택하거나 Host 주소를 직접 입력해 참가한다. IPv4/IPv6 연결을 시도하고 핫스팟도 실제 기기에서 별도 검증한다. 자리는 입장 순서이며 좌우 이웃은 해당 판 인원의 고리로 연결된다. 2인 판에서는 좌우가 같은 상대다. |
| 방 이름·조회 | Host 로비에는 Bonjour에 실제 등록된 방 이름을 표시한다. 참가자는 **FIND ROOMS**로 검색하고 목록의 방을 직접 선택해 입장한다. 발견된 같은 방의 IPv4·IPv6 경로는 목록의 한 행으로 묶어 접속에 사용한다. 검색 새로고침·취소와 직접 IP **JOIN**을 제공한다. 방 이름 등록 또는 검색이 되지 않으면 직접 IP 경로를 이용할 수 있다. |
| 세션 설정 | Editor·Development Build의 Host는 DEV 패널에서 숫자 56개를 조정해 네트워크 방에 적용할 수 있다. 49번째 값 `Player Max HP`는 1~300이며 기본 300이다. 53~56번째는 아이템 효과 값(물약 회복량, 릴레이 x2·MAX 배율, 폭탄 배율)이다. 참가자에게 동일 설정을 전파하고 확인을 받은 뒤 START를 허용한다. 로비에서 다시 조정하면 이전 확인을 무효화한다. 전투 도중에는 일시정지한 Host만 설정을 갱신하고 참가자 확인 뒤 새 판으로 재시작할 수 있다. 진행 중인 판의 값은 바꾸지 않으며 원본 설정 에셋도 저장하지 않는다. 솔로 조정 경로는 별도다. |
| 생성·자원 | 시작 구슬 0개. GENERATE 한 번에 Host가 Yin·Yang·아이템 4종(릴레이 구슬·시크릿 상자·회복물약·폭탄) 중 하나를 설정 확률(기본 40/40/5/5/5/5)로 정한다. 매 생성은 독립 추첨이며 같은 극성이 이어져도 보정하지 않는다. 한 개를 만들 때 개인 스태미나 20 소모. 100에서 시작하고 3초당 20 회복. 유효 명중의 실제 공격자에게만 5 회복. 보유 한도 20개. |
| 조합 | Raw Yin과 Raw Yang을 직접 드래그해 겹쳐 놓거나, 기본적으로 켜진 접촉 자동 결합 조건에서 서로 부딪히면 Combined 한 개를 만든다. 같은 극성 및 아이템은 결합하지 않는다. 두 Raw ID는 사라지고 Combined에 새 ID가 생긴다. 결합 순간 Host가 오행 속성(화·수·목·금·토)을 같은 확률로 정하고 스냅샷으로 모든 화면에 같은 값을 전달한다. 접촉 결합과 속도 기준은 DEV 설정값에 따른다. |
| 아이템 | 아이템은 잠긴 채 생성되며 잠금 횟수는 설정 범위(기본 2~4)에서 무작위다. 이웃 화면으로 넘어가는 전달을 Host가 승인할 때마다 1씩 줄고 0이면 해금된다. 1인 플레이에는 이웃이 없어 해금되지 않는다. 구슬 정면에 아이콘, 오른쪽 아래에 남은 횟수 배지를 표시한다. |
| 아이템 효과 | 해금된 **회복물약·시크릿 상자**는 같은 구슬을 0.35초 안에 두 번 탭해 그 자리에서 사용한다. 물약은 사용자의 개인 HP를 10(설정) 올리며 최대 HP를 넘지 않는다. HP가 가득 차 있으면 거절하고 물약을 남기며, HP 0인 플레이어는 쓸 수 없다. 상자는 양옆에 속성 구슬 2개를 만들고(새 8초 수명) 보관 칸이 하나 더 필요하다. **릴레이 구슬**은 해금 순간 ×1, 이후 이웃 전달마다 ×2·MAX로 오르며 배지 자리에 단계를 표시하고, 던지면 기본 피해 × 1·2·4(설정)를 준다. **폭탄**은 아이템 수명(기본 15초)이 끝날 때 던지지 않았다면 그 순간 보유자의 판 위 구슬을 모두 지우고 그 사람에게 알린다. 해금 후 던지면 기본 피해 × 3(설정)이며 빗나가면 폭발하지 않는다. 폭탄 위에 남은 초를 표시하며, 해금 전후 모두 전달할 수 있다. |
| 3D 조합판 물리·전달 | 소유자 화면에서 `Rigidbody`·`SphereCollider`의 3D PhysX 충돌을 쓰되 Z 위치·속도를 고정해 XY 평면에서 이동·감속한다. 상하 `BoxCollider`에서는 반발하며 좌우에서는 튕기지 않고 Host가 소유권 이전을 승인한 뒤 이웃 화면으로 높이·속도·구슬 ID를 이어 준다. 중복 전달은 승인하지 않는다. |
| 투척·피격 | Combined(해금된 릴레이 구슬·폭탄 포함)를 위쪽으로 움직이며 손을 놓는 입력으로 방향·세기를 구한다. Host의 3D Rigidbody 투사체가 **눈에 보이는 Unity Cylinder의 MeshCollider**에 실제로 맞아야 설정 피해(기본 20)를 적용한다. 빗나감은 피해나 명중 보상을 만들지 않는다. 투사체와 짧은 비행 잔상은 결합 구슬의 속성 색을 유지한다. Host가 확정한 명중에서만 실제 감소 HP 숫자와 맞은 위치의 확대 원형 효과를 모든 화면에 표시한다. |
| 전투 결과 | 기본 설정의 요괴 HP 1,000, 플레이어별 개인 HP 300, 제한 180초. 요괴 HP 0은 승리, 시간이 끝나거나 **모든** 플레이어의 개인 HP가 0이면 패배. 한 사람만 개인 HP 0이어도 전투는 계속된다. 시간은 Host의 단조 시계를 기준으로 진행하고 승인된 일시정지 구간을 제외한다. Host가 시작 전에 설정한 수치가 해당 판에 적용된다. |
| 전투 UI | 저장된 `LabCanvas`에 Figma `UI 가이드`의 조합대·일시정지·분:초 제한시간·요괴 HP·자기 HP·스태미나 볼/다섯 동적 칸·구슬 생성 버튼을 배치한다. 좌우에는 자리 기준 이웃의 기존 P번호만 보인다(2인은 양쪽 같은 상대, 솔로는 `P—`). 화면 값은 Host 확정 스냅샷을 사용한다. |
| 공동 일시정지 | 어떤 참가자든 요청할 수 있지만 Host가 승인해 전파한다. 판의 시간·구슬/아이템 수명·물리 진행과 게임 입력은 멈추고, Host만 재개하거나 모든 참가자를 같은 방 로비로 복귀시킨다. Editor·Development Build의 Host는 일시정지 중 새 DEV 값을 검증·전파하고 참가자 확인 뒤 같은 방의 새 판을 시작할 수 있다. |
| 개인 HP | 새 판 시작 때 Host가 각 플레이어의 개인 HP를 현재 세션의 `Player Max HP`로 초기화하고 스냅샷으로 동기화한다. 전투 화면에는 로컬 플레이어 자신의 HP만 표시하며, 결과 화면에는 마지막 확정값을 유지한다. Host 모델의 `TryApplyPlayerDamage`는 유효한 플레이어·양수 피해·진행 중인 판만 받아 0에서 멈추고 전원 0을 판정한다. 현재 플레이 중 이 경로를 호출하는 요괴 공격·DEV 피해 버튼은 없다. 회복물약은 개인 HP를 올리기만 한다. |
| 수명 | Raw와 Combined는 각각 생성 후 8초, 아이템은 15초에 만료된다. Combined는 조합 순간부터 다시 센다. 이웃에게 전달해도 수명은 이어진다. 수명은 설정에서 바꿀 수 있다. |

## 수정 지점과 교체 경계

`Assets/Lab/Resources/LabConfig.asset`이 수치 설정 원본이다. 여기서 요괴/개인 HP, 요괴 피해, 시간, 스태미나, 생성 확률, 구슬·아이템 수명, 아이템 잠금 횟수, 조합판 구슬의 3D 접촉 탄성·평면 감속, 투척 파라미터를 바꾼다. 코드는 설정을 읽어 판정하고 UI는 확정된 값을 표시한다. Host 확정 스냅샷만 요괴/개인 HP·시간·구슬 상태의 기준이다.

`Assets/Lab/Scenes/Lab.unity`의 Canvas, RectTransform, 카메라와 컴포넌트 참조는 Hierarchy/Inspector에서 배치한다. `LabHud`는 저장된 UI에 값을 연결하며 UI의 위치를 코드로 다시 만들지 않는다. `LabImpactFeedback`은 같은 Canvas에 붙어 Host 확정 명중의 숫자·확대 원형을 그리며, 표시 크기·수명은 Inspector에서 조정한다. 조합판 구슬은 ID·`SphereCollider`·`Rigidbody`를 가진 루트와 별도 `Visual` 자식으로 나뉜다. 조합판 구슬과 투사체는 공통 Unity 3D 구체 표현을 사용하지만, 조합판에서는 XY 평면 물리, 투척 뒤에는 3D 비행을 각자의 루트에서 처리한다. 속성별 재질·투척 잔상 머티리얼과 아이템 아이콘은 `Assets/Lab/Art/Orbs/LabOrbAppearance.asset`에서 교체한다(아이콘 원본은 `Assets/Lab/Art/Items/`). 아이템 아이콘·배지는 구슬 루트에 붙어 굴러도 회전하지 않으며 충돌체를 갖지 않는다. Cylinder 요괴도 피격 Collider와 교체용 시각 Mount를 나눈다. 향후 그림 에셋이 완성되면 **시각 자식만 바꾸고 판정·소유권·물리 루트는 유지**한다.

네트워크의 구슬 상태는 물리 컴포넌트가 아니라 기존의 ID·소유자·정규화한 XY 위치/속도·수명이다. 소유자가 자기 화면에서 물리를 계산하고, 좌우 전달은 Host 승인 뒤 동일 ID와 평면 운동량을 다음 소유자에게 넘긴다. 피격 숫자·원형은 Client 투사체의 독자 충돌이 아닌 Host의 확정 신호(구슬 ID·라운드·속성·실제 피해·요괴 기준 피격점)로 표시한다. 일시정지 상태도 Host 스냅샷에 포함된다. 프로토콜은 `5611`이며 이전 빌드와 같은 방에 들어갈 수 없다.

새 코드는 `Core`, `Session`, `Orb`, `Throw`, `UI`로 책임을 나눈다. 과거 `T01`·`T09` 같은 단계별 클래스나 Scene을 새 프로젝트에 쌓지 않는다. 단계 이력은 로컬 Git 커밋으로 추적한다.

## 이번 실험실에서 제외

- 오행 선택·속성별 공격 자격·속성별 효과(속성은 결합 구슬의 색 구분까지만), 랜덤 자리 배치
- 아이템 효과의 시각 연출(폭발 효과·회복 표시 등)
- Figma 가이드의 배경 풍경·캐릭터 그림, 새 요괴 모델·사운드 등 전투 UI 일곱 요소와 좌우 P표시 외의 그래픽 이식
- 요괴의 공격 패턴, 방어 입력, 전달 방해, 피버
- 개인 HP를 실제 플레이 중 감소시키는 피해 이벤트·효과(현재는 상태 보관·동기화·표시 및 Host 모델의 전원 0 판정까지)
- Photon·Relay·인터넷 매치메이킹
- 구 프로젝트의 전체 테스트 이식

이는 새 실험실의 **의도적인 제외 범위**다. 과거 프로젝트의 지원 여부와 동일하다는 뜻은 아니다.
